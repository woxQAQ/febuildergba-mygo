# 使用指南

运行方式见[项目 README](../README.md)，逐项支持范围见[覆盖矩阵](coverage.md)。下文描述当前编辑器的操作；字节布局和版本差异见[格式参考](README.md#格式与行为参考)。

## 打开与保存

通过“文件 → 打开 ROM…”或 Cmd/Ctrl+O 打开文件，每个 ROM 对应独立窗口。macOS 的菜单位于屏幕顶部；Linux／Windows 的“文件／编辑／视图”菜单常驻各自窗口顶部，窗口使用系统标题栏。下表的 Cmd/Ctrl 在 macOS 指 Command，在 Linux／Windows 指 Ctrl。未打开文件时，也可点击工作区的“打开 ROM…”按钮。顶部标签页切换人物、职业、道具、章节、文本、十六进制、事件脚本、头像、商店、战斗对话和支援；死亡对话位于人物详情内。

| 操作      | 快捷键           |
| --------- | ---------------- |
| 打开 ROM  | Cmd/Ctrl+O       |
| 保存      | Cmd/Ctrl+S       |
| 另存为    | Cmd/Ctrl+Shift+S |
| 撤销      | Cmd/Ctrl+Z       |
| 重做      | Cmd/Ctrl+Shift+Z |
| 放大界面  | Cmd/Ctrl++       |
| 缩小界面  | Cmd/Ctrl+-       |
| 恢复 100% | Cmd/Ctrl+0       |

有效修改先进入内存，保存才写入磁盘。保存前的完整文件保存在 `<ROM 文件名>.backups/`，备份目前不会自动删除。保存期间发生的新修改仍显示为未保存。

保存和窗口重新聚焦时会检查磁盘内容。若文件已被外部修改，可重新载入或另存，不能直接覆盖。关闭有未保存修改的窗口时，可选择保存、放弃或取消；保存失败会保留窗口和修改。

标题栏的百分比菜单与“视图”菜单调整整个窗口的界面大小，可选 75%、100%、125%、150%；也可使用上表快捷键，放大还接受 Cmd/Ctrl+=。每个窗口独立保留当前倍率，关闭后不保存。地图工具栏的倍率只调整地图，两者互不替代。窗口变窄或界面放大时，侧栏会让出编辑空间；恢复空间后还原用户调整的宽度，顶部标签可横向滚动。

右上角的“English”／“中文”按钮切换界面语言，可用 Tab 聚焦后按 Enter 或空格操作；切换会同步所有窗口和系统菜单并保存偏好。首次运行按系统语言选择，未支持的语言回退到英文。界面语言与 ROM 内的游戏文本编码互不影响。语言以外的编辑偏好目前未持久化；手动布局、视图和草稿不会随 ROM 保存。

## 修改、草稿与预览

普通字段的有效数值输入立即修改内存文档。不完整、超范围或输入法组合中的内容保留为输入草稿，不会立即写入。Tab 切换字段，上下键微调；右键数值框也可加减。悬停查看字段名称、允许范围和操作说明；人物／职业原始数据标签的字段帮助显示地址和十六进制值，其他领域页按用途组织少用选项；记录字段仍通过表单修改。

批量修改、名称与文本、PNG 替换、部署及条件事件、脚本编辑采用以下流程：

1. 修改草稿，查看当前输入和目标。
2. 点击预览，核对地址、共享用途和修改范围。
3. 应用后形成一次 ROM 历史操作，再保存到磁盘。

文档或表布局改变后，旧预览失效。出现冲突时，草稿会保留供检查，重新读取后才能继续应用。不同窗口的文档和历史相互独立。

菜单和快捷键按同一焦点目标撤销：搜索框、未应用的文本和数值草稿使用输入框自己的历史；地图编辑和地图变化区域及其审核视图使用草稿历史，菜单相应显示“撤销草稿／重做草稿”；记录视图和立即提交的数值字段使用 ROM 历史。草稿历史为空或草稿过期时，不会继续撤销 ROM。要撤销已应用的地图修改，先把焦点移回记录列表或其他编辑页面。后台操作期间禁止修改文档与领域草稿历史。

## 人物、职业与道具

记录列表支持名称或十六进制 ID 搜索。Shift 连选、Cmd/Ctrl 多选后，可在右侧选择字段、预览并批量应用；改变搜索会清空多选。

人物与职业详情提供“能力与特性”和独立“原始数据”标签，人物另有“支援”和“死亡对话”，职业另有“移动与地形”。基础信息随编辑区伸缩，窄窗口按字段组换行；职业的地图图像、行走速度和经验参数，以及人物版本特有的动画配色、对话语气直接在顶部编辑。地图图像编号旁显示实际预览。排序和访问分组在原始数据中编辑。人物显示个人修正、成长率和一行初始参考；职业来源及线性估算按需展开，武器熟练度紧接能力矩阵。估算不计上限、转职或实际游戏状态，也不写入 ROM。

人物列表只显示人物自身指定的头像，没有独立头像时不显示占位；职业待机图紧邻名称，不额外撑大行宽和行高。武器行显示武器类别图标、有效等级和精确原值，悬停可查看武器名称；点击武器等级标题就地选择等级，下方输入框直接修改熟练度。选择原等级会保留已有进度；人物原值 0 表示沿用默认职业。特性复选框只修改对应位，未知位保留；高级区可查看原始值。

点击身份区的大头像进入“头像”面板，编辑当前共享资源。右键“更换头像…”可在当前页看图选择，也可按名称或十六进制 ID（可带 `0x`）搜索；确认后只更换当前记录的引用，取消不修改 ROM，修改可撤销。没有头像时点击占位区域即可选择。人物菜单的“沿用默认职业头像”保存 0，职业菜单的“不设置头像”清空引用；继承状态下点击头像会打开实际使用的职业头像。头像可用 Tab 聚焦，Enter／空格打开，菜单键或 Shift+F10 调出右键菜单。小头像来源为 0 时沿用实际头像，非零值使用独立的通用小头像资源。

引用字段末尾的 `↗` 图标打开对应职业或文本；悬停查看目标，也可在字段内按 `Alt+Enter`，或用 Tab 聚焦图标后按 Enter／空格。选择框负责更换引用，图标只打开当前资源。支援、地形等已有专用表单的资源通过所属标签编辑，不提供字节编辑替代入口；“原始数据”标签只显示高级字段，不展开整条记录的十六进制字节。转职分支、技能和动画编辑器的范围见覆盖矩阵。详细布局及历史截图见[人物与职业编辑页](record-editor-design.md)。

## 职业移动与地形

选择职业，打开“移动与地形”。每行是一个地形 ID，列为移动消耗及回避、防御、魔防；FE7／FE8 另有雨天和雪天消耗，FE6 只有普通消耗。可按地形名称或十六进制 ID 搜索，例如 `0C`；窄窗口横向滚动表格。名称使用原生 ID 的译名，改版中的名称可能不同。

输入范围为 −128…127，移动消耗的 −1 通常表示不可通行；零和其他负值保留原含义。输入后点击“预览地形修改”，核对改值及保留原数据的职业／天气，再点击“应用地形修改”。只改变当前职业选中的列，共用同一旧表的其他入口保留；全部列一起应用、一起撤销。保存后才写入文件。

空指针或损坏的列显示原因，其他列仍可编辑。非法输入阻止预览；切换职业保留草稿，文档或布局变化后需放弃旧修改并重读。地形通过数值表单编辑。弩车移动、地形回复和自定义引擎规则有独立数据来源，详情见[地形参考](reference/terrain.md)。

## 名称与文本

人物、职业、道具详情可直接编辑名称、描述和道具使用描述。人物／职业的名称和描述文本 ID 位于“原始数据”，可输入十进制或 `0x` 十六进制数值；未设置 ID 时，点击对应的“设置文本 ID”直接进入该字段。“文本”页可浏览已有非零文本 ID，搜索正文或输入十六进制 ID，例如 `900` 或 `0x0900`。

道具关联字段、对话、支援与脚本等引用文本的位置提供选择框及打开入口。下拉选项显示 ID 与短摘要，完整正文在独立容器中显示，长内容滚动而不截断。引用预览显示可读正文，完整控制指令在文本编辑器中查看和修改。选择已有脚本中的关联文本只切换阅读对象；修改引用仍遵循所在页面的即时写入或草稿预览流程。

修改后先预览共享用途。同一文本 ID 的所有使用方都会变化；预览列出已知记录字段、原生支援及战斗／死亡对话表引用，包括 FE6 死亡记录中的终章文本；未列出的事件脚本等使用方也可能使用它。不同 ID 即使原来指向同一份文本，也会保留独立内容。

控制指令以 `[A]`、`[Wink]`、`[LoadFace][0x0141]` 等形式显示；`[NL]` 等同换行。字面 `[` 和反斜杠分别写作 `\[` 与 `\\`。指令参考可按需展开，在当前文本中收起再展开会保留面板滚动位置。

已确认的指令与参数可增删修改，但必须能由当前 ROM 的 Huffman 树编码。例如 FE7U、FE6 原版不能编码头像参数 `0x0101`，FE6 原版不能编码 `[Wink]`。无法无损解释的字符、未知控制码和不完整参数只读。

切换文本 ID 会保留草稿；原文改变时提示重新读取。恢复地址只供浏览，不能作为写入入口。当前不提供新建文本 ID、自定义字库或游戏画面对话预览。编码细节见[文本与静态图像](reference/text-and-images.md)。

### 文本文件批量修改

在“文本”页先搜索需要的内容，再到左侧列表底部点击“导出筛选文本…”。导出只包含当前筛选结果中可读取的 ROM 文本，不包含未应用的单条草稿；清空搜索可导出全部可读 ID。RAM 和损坏入口不导出，有不可读条目时列表下方注明跳过数量；草稿提醒也只针对当前可导出的筛选集合。文件使用 UTF-8、CRLF 和 `[十六进制 ID]` 分段，既可在外部编辑器中修改，也可与旧版原生标记格式交换。

例如：

```text
[0004]
A@0001@0080@0021@0010@0141B@001F
[0003]
@0000
```

正文中的 `@0001` 是游戏换行，`@0000` 表示空文本／结束；`@0010@0141` 保留完整头像参数。导出会将字面方括号、反斜杠、`@`、`/` 和 `{` 写为原生标记，避免被当作 ID、控制码或注释。导入也接受 `[NL]`、`[LoadFace][0x0141]` 等共有 FEditor 控制码。物理空行忽略；需要连续游戏空行时使用多个 `@0001` 或 `[NL]`。详细的注释和游戏语言条件规则见[文件参考](reference/text-and-images.md#文本文件)。

点击左侧列表底部的“导入文本文件…”后，审核页顶部显示当前文件名，按 ID 列出变化、未变化和错误条目，选择条目可阅读完整原文、新文及已知共享用途；宽窗口并排对照，窄窗口上下排列。审核时可应用、取消，或点击“重新选择文件…”载入修正后的文件；取消文件选择会保留原审核，读取或格式失败时显示错误并禁止应用，直到重新选择成功或取消审核。正文／控制码必须能由当前 ROM 字库和 Huffman 树编码；任意条目失败时“应用导入”禁用，修正文件后重新导入。重复 ID、零 ID 和未存在 ID 会拒绝整份文件；空内容文件、超过 16 MiB 或非 UTF-8 文件同样拒绝。

“取消导入”退出审核并保留原单条草稿。“应用导入”将全部变化的载荷、指针和文件长度作为一次文档操作，可一起撤销重做和保存重开；只清理本页实际修改 ID 的单条草稿，其他 ID 草稿保留，按原文冲突规则处理。相同正文或等价控制码不产生额外写入，独立文本 ID 的原别名保留。修改 ROM、布局或文档后旧审核不可应用，需要重新导入；离开文本页后的旧文件回调不会覆盖当前草稿。

## 头像与 PNG

头像 PNG 操作集中在独立“头像”面板，道具图标继续在道具页编辑。头像表支持 ID／使用者搜索、缩略图、主图、小头像、完整素材表、表情帧和部件地址；资源 ID 与人物 ID 分开。

替换素材时先导出当前 PNG，保持尺寸和布局，修改后导入，核对实际写入颜色及已知共享用途，再应用：

- 道具图标为 16×16，必须使用当前共享调色板。
- 普通头像为 128×112 完整素材表，包含小头像及眼口图块；职业卡保持导出尺寸。
- 头像最多 15 种不透明色加透明色，颜色会转换为 GBA 颜色。半透明和素材表空白区中的非透明像素会被拒绝。

同一资源 ID 的使用方一起变化；其他 ID 的旧别名保留。资源写入采用追加方式，旧区不回收，连续替换会增长 ROM，仍受 32 MiB 上限限制。

FE7／FE8 可调整眼口坐标和默认眨眼；FE6 提供嘴坐标与五个主图内口型。定位框按 8 像素格拖动，松开后一次写入 X、Y；帧选择和缩放只影响预览。换图与定位修改会使对方的旧预览失效，需要重新预览。

头像页直接提供图像预览、PNG 和定位表单，资源错误始终显示，不另设地址列表。详细版本规则、历史截图和扩展格式限制见[头像编辑页](portrait-editor-design.md)。

## 章节与地图

章节配置可编辑已确认的天气、迷雾、准备、音乐、地图与事件资源 ID。关联文本使用选择框和完整正文阅读区，点击“打开文本”进入文本页。胜利条件文案只影响显示，实际胜败由事件和引擎规则决定。

“配置”中的地图是由当前章节资源组合的静态预览，支持缩放、网格、拖动或滚动平移、重置和选格。单击格子查看坐标、图块值和地形 ID。切换章节会清除格子选择和平移；资源损坏时仍可编辑其他章节字段。

在“章节 → 地图编辑”中绘制基础地图或调整尺寸：

1. 从图块集中选择画笔；宽窗口中图块集位于画布右侧，窄窗口中位于画布下方。拖动画笔连续绘制；“矩形填充”以拖动的两个端点确定区域；“吸管”选取格子的图块后回到画笔。“平移”工具用于拖动视图。
2. 勾选“调整尺寸”，输入新宽、高，选择锚点，再点击“调整草稿尺寸”。应用到草稿后收起尺寸控件；尚未处理的输入会保持可见。锚点决定原有图块靠哪一边或居中对齐；扩大部分用当前画笔填充，超出新范围的格子被裁掉。居中时奇数差额多出的一行或一列位于下方或右侧。原生上限为宽 60、高 63、总计 1536 格；保留的解压尾部也计入当前读取上限。
3. 使用“撤销草稿／重做草稿”调整草稿，一次拖动或尺寸调整作为一步。图块与地形 ID 同步显示；切换章节会保留尚未应用的草稿。
4. 点击“预览地图修改”进入审核视图，检查尺寸、修改格数和同时更新的章节。尺寸变化时还会列出部署、移动节点、区域触发、地图变化矩形及可确认脚本坐标的影响，区分本次新增越界、原本越界和扩大后进入图内的部分。选中条目可前往对应入口或原始字节；不能静态确认的引用直接列在“未完整检查的部分”。“写入详情与检查范围”可展开地址和检查规则；“返回编辑”保留草稿和视图状态。
5. 检查后点击“应用地图”。共用同一个地图入口的章节一起变化；指向同一旧地图的独立入口保留。应用是一条可撤销的文档操作，保存后才写入 ROM 文件。

ROM 或章节布局改变时，旧草稿会保留并停止应用，需使用“丢弃地图草稿并重读”恢复编辑。共享章节的图块集无法解释新布局、入口冲突或 ROM 末尾容量不足时，不会写入部分数据。

尺寸调整只移动或裁剪底图，部署、事件与路径坐标保持原值。刻意放在图外的增援不会被自动拉回；越界提示供检查，也不会单独禁止保存。关联资源修改后，旧地图草稿会失效，需要重读再规划。

预览不模拟迷雾、图块动画、实际寻路或事件执行。脚本调用、分支、ASM、动态坐标与未知指令可能使检查不完整；未列出越界不等于全部引用安全。地图绘制保持图块定义、图像和调色板内容；定义与地图变化通过下文各自的视图编辑。

### 图块定义与地形

打开“章节 → 图块定义”，或在地图编辑器中点击“编辑当前图块定义”，编辑已有 16×16 图块的组成。通过编号、图块集或地图格子选择定义；四个位置各自设置 8×8 图块编号、调色板组和水平／垂直翻转，地形 ID 在上方单独输入。图块集和当前章节地图随有效修改刷新。

新组成必须引用当前图像中实际存在的图块，新调色板组为 0–4；第二份图像固定从图块编号 512 开始，未加载的编号不能使用。地形 ID 接受十进制或 `0x` 十六进制的 0–255 原始值，职业移动消耗、地形加成和名称另行编辑。已有未知值保持原样；配置项数不增加。

点击“预览图块定义修改”核对各组成项与地形的原值／新值、一起变化的章节，以及保留原配置的独立入口，再点击“应用图块定义”。共用同一配置入口的章节一起变化；图像、调色板和地图布局不改写。应用进入一次文档历史，保存后写入文件。

各章节及图块的输入独立保留；非法输入会阻止预览，可通过提示下的编号返回处理。图块定义与地图布局各自保留草稿，应用一方会使另一方未应用的草稿失效，操作前先完成需要保留的编辑。地图布局损坏时，仍可编辑可确认的图块定义；图块动画、迷雾显示和运行时地形效果不在此流程模拟。

本页还提供“导出 .mapchip_config”和“导入 .mapchip_config”。导出的是未压缩的整套图块组成与地形配置，包含当前有效手动修改；存在未完成或非法输入时先处理这些输入才能导出。完整原生文件为 9216 字节，可与旧版交换；页面标明当前长度，导入必须等长。短配置按原长处理，不能通过补齐文件扩容；短文件也不满足旧版导入器的最小长度。

导入后核对组成项、地形和共享章节的变化，以及替换后的图块集／地图，再点击“应用图块定义”。导入文件整份替换配置，不叠加先前的手动修改；点击“取消”可返回原手动草稿，未完成输入也会保留。文件与 ROM 配置相同时仅显示提示。新图块与配色沿用上面的限制，短配置缺少地形项的区域必须保留原值；额外尾部数据不被截断导入。

文件错误不会替换原草稿或写入 ROM。切换章节、页签、文档或重读后，旧文件回调不会发布导入；审核过期时禁止应用，先取消导入，再按需丢弃原草稿并重读。应用、取消或文件选择取消后，焦点返回文件入口。

### 地图配色 PNG

在“章节 → 地图配色”中选择“常规配色”“迷雾配色”或“全部十组”，点击“导出配色 PNG”。导出的是当前 ROM 已应用的颜色；每行 16 格、每格 8×8 像素，常规／迷雾为 128×40，全部为 128×80。

使用支持索引 PNG 的绘图软件，只编辑 PNG 调色板中的颜色，保持所有像素索引、色槽顺序和不透明度。重复颜色仍须保留各自的槽，0 号色同样不透明。不要将文件转为真彩色、自动合并颜色或用画笔重排色格；文件最多 1 MiB。

点击“替换配色 PNG”导入，核对颜色原值／新值、一起更新的章节，以及图块集和地图预览。“预览替换配色”可对照 ROM 原色，地图附近的常规／迷雾切换只改变预览用色；迷雾配色会应用到整个静态预览，不模拟实际视野。预览显示转换后的 GBA 颜色，无有效变化的文件会明确提示。

点击“应用配色”后，共用所选配色入口的章节一起更新，独立入口保留原色；图像、图块定义和地图布局保持原样。配色与指针、文件长度作为一次文档操作，可撤销重做，保存后写入 ROM。每次替换只追加原生 320 字节色表，不包含后方其他数据。

各章节和三个配色范围分别保留导入草稿，取消只丢弃当前范围；应用任一修改后，其他未应用的配色、地图布局和图块定义草稿会失效，先完成需要保留的编辑。“丢弃配色草稿并重读”会丢弃本章三个配色范围的草稿并读取当前 ROM。地图或图像损坏时，可确认的配色仍可独立导出和替换。

此入口只接受本页导出的色格索引 PNG，不从任意图像提取配色，也不处理旧版 `_swap_` 文件名或扩展色表。

### 地图图像 PNG

打开“章节 → 地图图像”，选择第一份或第二份图像，再点击“导出图像 PNG”。每份文件只包含该资源的原始像素，宽 128，每行 16 个 8×8 图块；资源内编号从 0 开始。第二份在游戏中仍从图块编号 512 加载，不需要在 PNG 前面补空白。未配置第二份的章节会明确提示。

“显示配色组”选择导出文件和像素表使用的颜色，0–4 为常规、5–9 为迷雾。用支持索引 PNG 的绘图软件修改像素，保持尺寸、图块数量与排列，只使用不透明的索引 0–15；末行未使用图块全部保持索引 0。文件最多 1 MiB。默认只替换像素；需要同时写入颜色时，勾选“同时导入配色”，再选择“导入配色组”。该目标独立于显示配色，文件须提供完整 16 个不透明颜色，包括当前像素未使用的颜色和 0 号色。颜色按原索引写入选定一组，其他九组保持原样。

点击“替换图像 PNG”，核对变化图块数；联合导入另显示冻结的目标配色组、变化色槽与前后颜色。“预览导入结果”可切回 ROM 原图；替换预览显示新像素及实际 GBA 颜色，联合导入会自动切到目标配色与对应常规／迷雾预览。图像和配色的共享章节分别列出：同一图像入口可能被其他章节用于第一份或第二份，两类用途一起变化；配色入口还可能被未共享图像的章节使用。独立入口继续使用旧资源，列表只包括可确认用途。

点击“应用导入”后，变化的压缩图像、完整色表、所选指针和文件长度作为一次文档操作，可一起撤销重做；保存后写入 ROM。仅像素或仅颜色变化时只追加变化的资源，等效颜色量化后无变化则不产生写入。图块编号、定义和地图布局保持原样。各章节及两份图像分别保留草稿，取消或重读只丢弃当前流；应用修改会使其他未应用草稿失效，先完成需要保留的编辑。应用、取消和重读后焦点返回文件入口。

损坏的地图布局、配置或另一份图像会单独报告，不阻止有效图像资源替换；配色不可读时不能导出彩色 PNG 或联合导入，但仍可仅导入已有的有效索引文件。此入口保持现有数量和排列，尚不接受旧版组合图像自动拆分、自动减色或真彩色转换。

### 地图变化与脚本引用

在“章节 → 地图变化”中编辑门、村庄、桥梁等变化。列表中的 ID 是事件使用的编号，不是行号。

1. 选择一项，修改 ID、X、Y、宽、高后点击“更新草稿属性”。移动保留图块；调整尺寸保留左上交集，新增格子为 0。未处理的属性输入会阻止预览和切换记录，可用“重置属性输入”恢复。
2. 在选中矩形内使用画笔、矩形填充或吸管。“保留原格（0）”使该格不替换现有地图；它与底图中编号为 0 的可见图块含义不同。“查看底图”用于对照，期间停止绘制。预览只叠加当前一项，不模拟其他已启用变化。
3. 可新增、复制或删除变化。新增／复制分配尚未使用的 ID，仍可手动修改；草稿撤销重做涵盖属性、绘制和增删。
4. “预览地图变化修改”列出同时更新的章节、保留的独立入口和已确认脚本引用。按坐标引用可能因移动、增删或重叠而改指其他 ID；已有重复 ID 时，删除首项也可能改变实际目标。目标丢失会禁止应用；无法确认的上下文单独提示。
5. 应用会追加变化表及修改的图块载荷，保留旧资源和未修改载荷，一次进入文档历史。保存、重开后仍可从章节或脚本继续编辑。

脚本参数区的“选择地图变化”使用当前可确认的地图上下文；链接按钮进入对应章节和变化项。变化页选中引用可返回脚本入口。脚本已修改或输入无效时，先处理脚本草稿再跳转。显式加载另一章地图后的指令会使用那一章的变化资源；不能确认上下文时保留数值编辑及诊断，不猜测目标。

重命名被引用的 ID 时，可先复制为新 ID 并应用，再修改已确认脚本引用，最后删除旧项。编辑器不会批量改写脚本、引擎自动触发或未知引用。引用审核限于共用变化入口的章节及其可确认线性上下文，不包含所有跨章节进入路径；动态参数和不完整提示需要结合事件设计判断。

FE6／FE7 支持按 ID、坐标及事件参数应用变化，FE7 另有立即、静默、水面阴影和地图刷新操作。FE8 的应用／恢复接受直接 ID，或 -1（槽 B 坐标）、-2（行动单位位置）、-3（队列 ID）。恢复会把整个矩形还原为原始底图，可能覆盖其他重叠变化；它不是只恢复非零格子。具体参数规则见指令帮助。

### 部署与 FE8 移动路径

在章节“部署”视图选择入口。列表区分难度、路线、遭遇战以及静态发现的事件引用。地图显示所选组的编码位置，不表示游戏运行后的实际开场状态。

宽窗口左侧是地图和单位列表，右侧编辑所选单位；窄窗口上下排列。人物、职业、领队和道具可按名称或十六进制 ID 搜索，字段末尾的打开图标进入对应资源。职业 0 显示为“沿用人物职业”，领队和道具 0 显示为“无”；未解析的 ID 仍可选择。阵营直接选择自军、友军、敌军或保留值，自动成长通过勾选设置；等级、位置和 AI 在相应分组编辑。单位列表旁可新增、复制或删除单位。

地图默认适应画布，工具栏可切换起点／终点、缩放、网格和重置。列表与地图互相定位，同格单位可循环选择；选格后，通过地图下方的按钮设置当前单位的起点或终点。

FE8 在所选单位右侧切换到“移动路径”，新增、复制、删除和重排移动段；地图下方仍可选择其他单位。地图以编号节点和折线显示绝对目标，重叠节点可循环选择；同步人物控制等待时机，不改变目标坐标。编辑后最多 16 段，实际逐格寻路和落点由游戏决定。FE6／FE7 继续使用起终点字段。

预览部署时核对目标地址、单位数量和共用同一指针位置的已知章节。这些章节会一起变化；其他独立指针继续使用旧资源。切换章节或入口会保留草稿；文档或布局冲突需要重新读取。

### 回合与区域增援

“回合增援”可编辑起止回合、触发阶段、完成标志及 FE7 路线／难度。结束回合 0 表示仅起始回合，255 表示无上限。触发阶段与部署单位阵营分别设置。

新增回合增援默认在第 3 回合敌军阶段触发。在同页编辑独立部署组，预览后一次应用条件、加载单位脚本、部署和修改路径。已有事件可跳到“部署”编辑已识别单位，不重写原脚本。

“区域事件”可编辑两个端点和完成标志。区域包含端点；FE6／FE7 要求端点顺序正确，FE8 接受倒序。地图支持选择重叠区域和选格设置端点。新增区域增援默认范围为 `(0,0)…(0,0)`。

完成标志 0 允许重复触发；单次触发需显式选择未占用的非零标志。编辑器不会自动分配标志，也不执行事件条件或 ASM 来模拟实际触发。

### 人物对话与胜败条件

“人物对话”编辑章节内有方向的发起者、目标人物关系；双向对话需要两条条件。新增普通对话选择已有文本 ID，按版本生成文本展示、清理和结束脚本。头像和发言位置由文本控制指令决定；招募、阵营和道具效果仍由事件脚本决定。

“胜败条件”可编辑已确认的标志和全灭条件，关联本章已有脚本或原生标记。首领击破模板使用标志 2，它必须由死亡对话或脚本设置；模板不会指定某个人物为首领。新增条件不会自动替换既有占领、死亡或其他引擎规则。

区域与胜败页共用常驻条件表草稿，一次预览与应用包含两页修改。胜利文案、实际条件和结束事件分别提供入口。

### 地点事件

在章节的“地点事件”页编辑民家、村庄、宝箱、门、占领点和商店。宽窗口同时显示地图、地图下方的地点列表和右侧属性；窄窗口按上下顺序排列。地图工具栏集中提供新增、缩放、网格和重置；默认适应画布，也可选择固定缩放。列表显示原生类型、坐标和完成标志；选择记录可定位地图，同格多个地点可循环选择。点击“设置位置”后，在地图上点击新位置，或按 Esc／点击“取消”退出。切换章节、页面或所选记录会取消待执行的位置设置。

点击“新增地点”后选择地点类型，再在地图上点击落点；落点前可以取消，不产生草稿记录。地图不可读取时，可在 `(0,0)` 新增，再编辑坐标。民家／村庄需选择已有文本，或改为关联已有章节脚本；占领默认使用完成标志 3 和本章结束事件，缺少结束事件时不能创建。门默认使用原生处理，按坐标应用已有地图变化。村庄和宝箱也需要对应的地图变化，编辑器不会自动创建它们。

宝箱可编辑原生道具值及金币数量。“改为金币奖励”会设置当前版本的金币标记；FE8 金币至少为 256，FE6／FE7 允许低额金币，当前版本范围显示在奖励字段旁。复制完整地点记录保留已有资源引用；新建对话的复制记录可以独立选择文本。完成标志 0 不阻止重复触发，单次事件需选择未占用的非零标志。

属性栏按地点类型显示触发内容；访问文本在带边框的滚动区显示完整可读正文，文本选择与“打开文本”按钮位于上方。“更换关联脚本”展开已有脚本选择；“本章脚本”浏览整章，“编辑此地点脚本”打开当前地点入口。修改先进入草稿，属性栏突出“预览地点修改”；预览同步变化的章节后，主操作变为“应用地点修改”，一次提交地点表、新脚本和修改的商店货物。“放弃草稿并重新读取”丢弃本页未应用的修改，恢复当前文档中的地点表。关联脚本修改后，先应用再进入脚本页；文本和已发现部署可直接导航。FE8 随机宝箱及未知条件保留原数据，随机奖励内容暂不编辑。裁剪地图时，预览会列出已确认地点的越界变化。

选中商店后，可切换武器店、道具店或秘密商店，在货物列表中新增、删除或上下排序；选中货物后按名称或十六进制 ID 搜索道具并选择替换。最多 20 项，允许空列表。所选货物直接显示“补丁参数”输入，含义见字段帮助，非法输入保持可见：原生引擎按道具表生成耐久，扩展补丁可能将它用于耐久或技能 ID；替换道具保留此字节，新增项默认为 0。

“新增地点”选择商店并在地图落点，即可建立空商店后添加货物。复制商店后，两个地点的货物草稿可独立修改。预览列出原货物的已知使用处；修改只为所选地点创建新货物列表，共用其地点表入口的章节随之更新，其他独立引用继续使用原货物。货物无法解析时单独显示原因，不阻止其他地点修改。准备界面和世界地图货物从顶部“商店”页进入。

### 统一商店列表

“商店”页在侧栏顶部通过来源下拉框筛选全部、章节、准备界面、引擎默认货物和世界地图，可搜索章节／据点名及十六进制 ID。选中入口后直接编辑货物；章节商店的“打开章节地点与位置”返回原地图编辑流程。两页的未应用草稿分别保留，在任一页应用后，另一页旧草稿会提示重新读取。

FE6、FE7、FE8 都有引擎默认货物，供调用时未指定货物列表的商店使用。修改它会影响所有此类调用；预览列出可确认的入口，其他脚本调用可能也受影响。FE6 的此入口按默认货物命名，FE7 不提供准备界面或世界地图商店。

FE8 的准备界面商店单独编辑。若入口正在使用默认货物，页面会说明；修改后只为准备界面创建独立列表。

FE8 世界地图按原生据点列出武器店、道具店和秘密商店，默认隐藏已关闭和待初始化的入口。勾选“显示未启用入口”后可查看这些配置，列表分别标明“未启用”或“待初始化”。已有空列表可直接新增货物；零指针入口需先点击“初始化货物”。预览并应用后才启用库存。尚有未应用修改或非法输入的草稿会继续显示，避免取消勾选时隐藏待处理内容。

“关闭此据点商店”会创建有效空列表，保留据点其他设置；已经关闭的空草稿不能重复关闭。少数原生编码虽然没有货物，菜单入口仍未关闭，页面会说明并保留关闭操作。关闭草稿应用后，入口回到未启用筛选中。能否在游戏中进入仍受据点状态、剧情进度及秘密商店通关条件约束。

点击“预览商店修改”检查将变化的入口及原货物共享处，再“应用商店修改”。准备和世界地图修改仅更新所选入口，原货物及其他独立引用保留；默认货物修改则由回退调用共同使用。指针、货物和扩容可一起撤销／重做，并按普通保存流程写入文件。

### 世界地图据点

FE8J/U 在顶部“世界地图 → 据点”页编辑已有据点。侧栏可按地名或十六进制 ID 搜索；先选择据点，再修改坐标、地名文本引用、两条路线的章节和后继据点。章节与后继输入可搜索名称或输入十进制／0x 十六进制编号。地名正文通过“打开文本”编辑；文本修改预览中的据点使用处可返回本页。

据点地图显示日间／暗色底图和原生 ID 标记，支持 50%、100%、200% 缩放及滚动。点击标记可同步选择列表与详情；重叠标记可再次点击切换。勾选“点击地图定位此据点”后，点击底图修改所选据点的 X/Y 草稿，再用坐标框精调；Esc 退出定位。切换据点或标签、输入非法值、处理文件或草稿过期时会退出定位。底图外的有符号坐标仍保留，可通过坐标框或定位移回可见区域。

此入口对应 FE8 的世界地图据点系统。FE6／FE7 的世界地图是章节间演出，不显示这个据点／路线编辑入口。FE8 改版即使取消大地图行走，保留的据点数据仍可编辑；页面不会检测这些数据是否实际被游戏流程使用。

后继据点分为普通和分支两组，分支标志成立时使用分支组，两组都按当前路线选择。输入 -1 表示没有下一站。坐标为像素，移动据点不会同步移动道路或脚本路径。“其他据点规则”提供图标、放置／遭遇类型及乘船位，取值说明在字段帮助中。

点击“预览据点修改”核对原值和新值，再“应用据点修改”，最后 Cmd+S 保存。一次据点修改可一起撤销／重做。各据点未应用输入独立保留；非法输入阻止预览，ROM 或布局变化后保留原草稿并要求放弃重读。

据点下方的武器店、道具店和秘密商店按钮会打开对应货物，包括尚未启用的入口；商店页的“前往据点”可返回据点。两页各自应用后会使另一页旧草稿失效。据点字段修改不覆盖货物指针，货物修改不覆盖其他据点字段。

据点和路线通过表单及地图编辑。支持范围见[覆盖矩阵](coverage.md#世界地图据点)，格式与特殊值见[世界地图参考](reference/worldmap.md)。

### FE6 世界地图演出

在“事件脚本”中选择章节，打开对应的“进入章节事件”；“世界地图与结局”汇总当前章节明确引用的演出入口。此处的编号是资源指针表索引，不是章节号。多个章节可能共用同一入口，预览会列出确认的影响范围。

选择旁白、头像、缩放、箭头、区域高亮、圆点、旗帜或图像标签指令编辑参数。头像有四个槽；圆点、高亮和图像标签各有两个槽，旗帜有四个槽。箭头选择原生轨迹编号，图像标签选择预绘图形；它们不通过文本编辑器修改。图形与演出范围见[FE6 参考](reference/worldmap.md#fe6-章节演出)。

预览、应用、撤销重做及保存沿用通用脚本流程。已声明的零指针入口可以显式创建，包括资源索引 0；先检查共享章节。可重定位脚本的结构修改只替换所选指针项，原代码和独立引用保留。含 ASM 回调或未解释操作时保留参数编辑，禁用结构编辑；实际播放需要游戏内另行验证。

### FE7 世界地图演出

打开“事件脚本”，选择章节后可找到对应的“进入章节事件”；选择“世界地图与结局”可浏览完整 00–2C 目录和艾利乌德／海克托尔结局。FE7J/U 沿用事件脚本页，世界地图据点／路线页仍只适用于 FE8。

选择旁白、头像、地图单位、镜头滚动、区域高亮或地点圆点指令后修改参数。头像可选 0–3 号槽位，地图单位可选 0–4 号槽位；职业只在新建地图单位时使用。预览会列出共享脚本的已知使用处，应用参数修改会影响这些共用代码的入口；一次修改可一起撤销，并按普通保存流程写入文件。

区域高亮使用独立的 0–3 号槽，选择区域图形 0–8；已占用的槽保留原区域，需要更换时先移除。可以单独移除一个高亮、立即清除全部高亮，或开始淡出全部高亮；淡出后脚本会继续执行。地点圆点使用独立的 0–4 号槽，可编辑像素坐标、调色板组和启动延迟；已有圆点移动时保留原配色。标记效果不在编辑器中播放，可结合旁白与镜头编排，并在游戏内检查时序。

原版场景常含跳过事件时执行的 ASM 回调或尚未解释的效果指令：已确认参数仍可编辑，插删重排和整体搬迁会被禁用。空入口可创建脚本，完整可重定位场景的结构修改只更新所选指针，保留独立引用和原载荷。旁白与头像预览不模拟游戏演出；格式与范围见[世界地图参考](reference/worldmap.md#fe7-章节演出)。

### 世界地图路线

在“世界地图”内切换“路线”，或从据点点击“查看相连路线”。侧栏保留原生路线 ID，可按端点名称筛选；“显示全部路线”清除据点过滤。端点输入支持名称候选、十进制或 `0x` 十六进制 ID，旁边的“前往据点”可返回据点。

地图显示日间底图、所选路线的道路草稿、据点编号和移动控制点。连线只表示控制点顺序，游戏仍使用样条插值。圆点标记据点，方点标记中间控制点；点击方点选择它，勾选“点击地图定位所选点”后点击地图修改坐标，也可直接输入有符号像素值。地图支持 50%／100%／200% 缩放及滚动。

“插入控制点”插在选中点之后，没有选择时追加；最多六个中间点。进度不是帧数，而是总移动时间的 1/4096，须在 1–4095 内严格递增。起终点坐标来自对应据点，进度分别为 0 和 4096。删除或重排后可继续调整进度；过近的进度还需要结合游戏里的移动时长验证。

选择“画笔”后从道路图块集中取图块，可设置水平／垂直翻转，在地图上拖动绘制；“取样”保留原格子的图块及翻转，“擦除”移除格子。透明图块仍会覆盖重叠道路，擦除则不会。一次拖动可一次撤销；方向键移动选择，空格绘制／擦除／取样，Esc 取消未松开的笔画。道路工具及画布中的撤销命令作用于道路草稿，输入框保留自己的文本撤销。地图只显示所选路线。

先“预览路线修改”，确认端点、控制点、道路变化格数、追加位置及仍使用原数据的其他路线，再“应用路线修改”并保存。改过的道路及轨迹独立追加；清空轨迹改为直接连接，擦除全部道路保留有效的空道路。原载荷和其他路线不变，整次修改可以一起撤销／重做。各路线输入及笔画历史独立保留；非法输入阻止预览，文档变化后已有修改需要放弃重读。

连接修改不会重绘道路，也不会修改据点后继、剧情中的开放路线指令或路线容量。图形读取失败时仍可编辑有效的端点记录；原轨迹或道路无法确认时停止自动改写对应资源。

### 世界地图底图

在“世界地图 → 路线”的地图附近选择“日间”，展开“PNG 导出与替换”，点击“导出底图 PNG”，用外部绘图软件修改后，通过“替换底图 PNG”导入。保存时保持 480×320 索引 PNG 和调色板编号；每个 8×8 图块只使用同一组 16 色（0–15、16–31、32–47 或 48–63），颜色须不透明，文件不超过 1 MiB。不要将图片转为真彩色 PNG 或自动重排调色板。

导入后地图叠加现有据点、道路和控制点，勾选或取消“预览日间底图”比较位置。颜色会转换为 GBA 颜色，以预览为准；确认后“应用日间底图”，再按普通保存流程保存 ROM。所有路线共用该底图，应用可一次撤销／重做；取消预览不修改 ROM。底图操作不会移动据点或道路。

修改日间底图后，可切换“暗色”检查新像素与原暗色调色板的组合。先应用日间修改，再切换“暗色”，展开“PNG 导出与替换”并点击“导出暗色 PNG”；外部软件只修改调色板颜色，保持每个像素的索引和调色板顺序，随后导入、预览并应用。暗色导入只替换独立暗色调色板，不改变日间颜色或像素。

“PNG 导出与替换”内的“导出道路图块 PNG”提供所有路线共用的图块表。保持导出尺寸与图块顺序，每行 16 个图块；只用 0–15 号色，其中 0 号透明，其余不透明，末行空格保持透明。通过“替换道路图块 PNG”导入后，可切换路线查看影响，也可用预览图块试画；关闭预览可对照原素材。成功导入后文件操作自动收起，预览与应用操作留在地图前；需要查看格式要求或重新导入时可再次展开。错误和草稿失效提示不会随文件操作隐藏，应用或取消后键盘焦点回到“PNG 导出与替换”。应用只替换共享图块／调色板，道路布局和图块编号不变。素材与道路布局分别应用，任一应用后，其他尚未应用的草稿会按文档修订失效。完整支持范围见[覆盖矩阵](coverage.md)。

### 世界地图事件

FE8J/U 在“事件脚本”的章节选择器选择具体章节，可编辑关联的世界地图开始／进入章节脚本；选择“世界地图与结局”浏览完整目录、开场和两条路线的结局，并按事件 ID、来源或地址搜索。开始和进入章节目录使用章节的“世界地图事件 ID”，不等同于章节编号；开场对应开始表 01。

画好道路并应用后，在路线详情展开“查看引用事件”，就地查看已确认使用该路线的章节与事件类型，点击“编辑事件脚本”直接修改开放／关闭路线等指令。据点详情也提供相同的引用列表；展开状态按据点／路线分别保留。参数旁可选择现有据点或路线，并跳回其编辑页面；单位放置、沿路线或坐标移动、等待和镜头操作使用各自的原生参数。沿路线的负时长保留原生自动计时含义；等待单位移动的 -1 表示全部单位。

选择“世界地图旁白”可查看并更换已有正文，通过“打开文本”编辑内容。头像指令支持槽位 0／1、头像资源、横坐标、滑动、镜像、层级和延迟；下方显示原头像并可跳转素材页。预览不模拟镜像、移动或台词时序。清除头像的延迟是无符号帧数，显示头像的负延迟则保留原生延迟进程行为。

完整可重定位的场景可插入、复制、删除和重排旁白、头像、路线及转场指令。底部／顶部旁白显示、正文和等待分别控制；“结束世界地图场景”只停止世界地图显示，后面仍需普通事件结束指令。编辑器不执行或检查整段演出的时序与运行状态。

先预览共享使用处，再应用并保存。参数修改会改变共享代码；可重定位的结构修改及空入口创建只更新所选指针位置，共用这一位置的章节仍一起变化。切换页面保留草稿，其他文档修改会使旧草稿失效。遇到未知指令、动态调用或损坏资源，引用搜索显示不完整提示，未列出不代表没有使用；未知结构不能自动搬迁，也不模拟事件执行或证明游戏中已开放路线。

### 战斗与死亡对话

顶部“战斗对话”页显示人物姓名、头像与双方配对，列表不再拼接人物／文本的十六进制编号；FE6／FE7 仍分开列出双方、通用与三角攻击。十六进制编号可以继续用于搜索及字段核对。FE8 提供“全部战斗对话／指定双方／单人通用／三角攻击”筛选；这些记录共用同一张原生表和同一份草稿。单人记录区分“主动进攻”与“受到攻击”，三角攻击条件可以与双方或单人条件组合。在单人或三角攻击筛选下新增，会设置对应的原生条件。

人物详情的“死亡对话”标签直接显示台词。点击“编辑台词”进入文本页，“更换台词”选择已有文本；两处不重复显示正文。引用或范围有未应用修改时，点击“应用后编辑台词”，审核后使用“应用并编辑台词”提交引用并进入正文编辑。单条通用对话不显示章节／路线控件；已有特殊情形时显示实际范围，多条情形才提供切换，FE7 的琳篇和其他篇章脚本也列在其中。

从“对话操作 → 添加特殊对话…”选择章节／路线与内容，确定后才形成对话草稿，新特例排在该人物当前表的已有记录之前。修改适用范围、死亡标志、备用脚本和 FE6 终章台词分别打开对应任务；取消或 Esc 不改变原草稿。“改用脚本”会清空本条文本字段；更换台词保留已有备用脚本。当前非零死亡标志和已有终章台词可直接点击编辑，`0x65` 的说明保留版本与场景限制。

尚无记录时直接添加死亡台词；缺失的 FE7 篇章脚本从对话操作新增。复制、删除、移动和匹配规则也位于操作菜单。每个人物各自保存草稿，切换人物不会丢失输入；删除当前表的最后一条对话后，仍可返回该表的待应用修改。应用当前人物的修改不会提交其他人物的待处理草稿。

独立对话页先选择表，再按角色名称、角色／文本 ID 或记录序号搜索；数值搜索按十六进制解释。可添加、复制、删除和上下移动记录，移动改变完整表的原生匹配顺序。人物、章节和文本字段搜索后需选中结果才会修改，标志可直接输入十进制或带 `0x` 的十六进制。表中已有未知字节及终止记录保留。“匹配规则”展开当前版本的战斗或死亡匹配流程；搜索、移动和字段的帮助提示说明对应操作。

角色和章节可跳转到记录页；文本选择和正文预览显示可读文字，打开文本编辑器可查看或编辑完整控制指令，文本页的使用处也能返回对话记录，死亡对话返回所属人物的标签；无法关联原生人物的扩展记录保留独立表入口。脚本字段接受已有脚本的十六进制 ROM 偏移或 GBA 地址，0 清空引用，“查看脚本字节”打开十六进制页。这些全局入口没有自动归属章节，独立对话脚本的结构编辑仍需相应上下文。

修改后出现“预览对话修改”和“放弃草稿并重新读取”。预览列出完整新表位置和将更新的已知原生入口。确认后点击“应用对话修改”，表、入口和扩容一起撤销／重做；旧表及其他独立引用保留。文档或手动布局改变后，修改过的草稿会提示过期，需“放弃草稿并重新读取”。非法输入仍保留草稿放弃入口；读取失败时可“重新读取”。同表的检测、播放等入口已指向不同地址时，停止自动重定位，并保留读取失败的原因。

任意章节为 FE6 的 `2D`、FE7U 的 `43`、FE7J 的 `45`、FE8 的 `FF`。FE8 战斗表 `FE` 还允许三角攻击；死亡路线 `FF` 表示任意路线。死亡记录的文本和脚本都为零，不代表记录无效，FE8 仍可能设置标志。标志 `65` 的实际游戏结束效果取决于版本和场景，章节胜败事件需另外配置。超出原生范围的角色字不会被人物选择器覆盖；击杀者等扩展条件使用原始字节处理。具体匹配顺序与写入边界见[格式参考](reference/battle-and-defeat-dialogue.md)。

### 斗技场

打开“斗技场”页，在近战、远程、魔法对手、武器和适用版本的联机限制之间切换。支持范围见[覆盖矩阵](coverage.md#斗技场规则)，原生格式和写入边界见[斗技场参考](reference/arena.md)。

职业列表可添加、复制、删除和上下移动；重复行提高抽中概率，预览要求同时保留上下级职业。选中一行后按编号或名称搜索记录，也可输入十进制或 0x 前缀编号，再通过“前往记录”查看职业、道具或人物。

基础武器按类型显示，升级表在下方；两表共用草稿。更换基础武器时同时调整它在升级表中的匹配项，然后预览。升级表的零分隔和 FF 标记保留，不能扩容。FE8 联机限制保留 11 个固定槽，输入零只清空当前槽，后续槽仍生效。

当前组标签的帮助提示说明编辑规则。修改后使用“预览修改”进入原值／新值对照，确认后“应用修改”；“继续编辑”返回并保留草稿与选中行。武器组同时应用基础武器和升级表，其余组独立应用。原数据和独立引用保留，统一撤销可还原本组的全部指针、载荷及文件长度。规则编辑不提供地址和字节编辑替代入口。

切组保留各自草稿。非法输入阻止预览；其他编辑改变 ROM 或布局后，旧草稿保留并禁用写入，需明确放弃并重读。只有已应用的内容会随 Cmd+S 保存。

### 支援

人物详情的“支援”标签编辑当前人物的关系；顶部“支援”页可切换“支援对话”和“属性加成”。三个面板分别保留草稿、预览和应用，切换人物或面板不会丢弃未应用输入。

关系行可选择对象、修改初始值与增长值，并添加或删除对象。FE6 最多 10 项，FE7／FE8 最多 7 项；空指针人物添加对象后，应用时创建独立数据。删除对象只改当前人物，其他人物及对话记录保留。“同步已有反向关系的数值”默认关闭，启用后同步本次改变的初始值与增长值；缺少反向关系会列在预览中，不会自动替另一方增删对象。

关系行的“对话”跳到这组人物的已有对话，“查看此人物的对话”列出包含当前人物的条目。独立对话面板按表序列出双方人物，可搜索名称、ID 或用 `#001` 精确定位十六进制记录编号；“全部对话记录”清除人物筛选。点击双方人物按钮回到各自的“支援”标签。重复配对分别显示，列表中的 `*` 表示该条目有未应用修改或非法输入。

对话面板可选取或输入 C／B／A 文本 ID，零表示无对话；“打开文本”进入正文编辑器，文本使用处可直接返回相应对话记录。双方交换也能匹配，重复配对以首个匹配项生效。配对、表序和音乐数据保留，不提供对话表扩展。关系记录损坏时，有效对话仍可独立编辑。

“属性加成”按原生表序显示攻击、防御、命中、回避、必杀和必杀回避，输入范围为 0–255。这些是每级支援的原始贡献值；原生游戏将双方贡献按等级以字节累加，再除以 2，大数值可能在相除前回绕。字段帮助说明计算方式。属性 ID、记录顺序和未知字节保留；额外 ID 以编号显示，后出现的重复 ID 提示前一条优先。

各面板点击“预览支援修改”后，核对列出的改动再“应用支援修改”。人物面板列出关系变更、反向同步和保留原数据的其他人物；对话面板列出所有已改条目的文本 ID；属性加成面板列出六项数值变化及当前可确认的同属性人物，可返回人物支援页。人物表无法读取时提示使用处不完整，但有效的加成表仍可编辑。应用只提交当前面板的草稿，一次进入 ROM 历史，Cmd+S 保存。另一面板或正文产生新修订后，尚未应用的旧草稿会保留并提示过期；须明确放弃并重读。修改不会迁移已有游戏存档的支援进度，具体原生边界见[格式参考](reference/supports.md)。

### 通用事件脚本

“事件脚本”页按章节列出开场、结束、条件及已发现调用入口，可按来源或地址搜索，并跳转文本、部署、调用和标签。当前支持常用指令及已确认的版本参数；ASM 和未知指令只读，边界或结束不完整时整段只读。

选中入口后，在指令表中选择一行，下方直接编辑参数。“增删与排序”展开插入、复制、删除和上下移动操作；各入口保留展开状态及草稿。窄侧栏优先显示来源与事件编号，完整名称及地址仍可在详情和悬停提示中查看，也可继续按地址搜索。

可插入背景切换、场景隐藏／恢复、音乐／音效、黑白渐变、单位移动和阵营变更。人物与道具参数提供现有表的名称选择，也保留数值输入；移动后需要等待到达再继续时，插入“等待单位移动”。FE7 提供普通移动与指定速度移动，FE8 移动中的负速度表示直接放置。坐标显示原生编码，编辑器不模拟寻路。

例如，在普通对话结束后插入“加入我方”，选择人物，再插入“移动单位”和“等待单位移动”，即可编排招募后的移动。FE6／FE7 可插入“给予人物道具”并选择接收者和道具。FE8 先插入“设置内存槽”，将槽 3 设为道具值或金币数量，再插入“给予槽 3 中的道具／金币”；奖励指令本身只选择接收者。槽值由前面的脚本决定，不会自动补入或推断。

FE8 的人物选择值 0、-1、-2、-3 分别代表我方领队、当前行动单位、槽 B 坐标处的单位、槽 2 中的人物。负音乐／音效／背景 ID 读取槽 2。事件执行位控制当前脚本，和完成标志分开；位 7 取消结束淡出，位 9 让镜头跟随移动单位。参数说明随指令和版本显示。

镜头可按人物或坐标定位；FE7／FE8 另提供居中坐标，FE8 还可居中人物。居中受地图边界限制，不代表镜头瞬移。FE8 镜头／光标任一坐标为负时，两个坐标都从槽 B 读取。FE6／FE7 的人物或坐标闪烁会等待约 60 帧后自行结束；持续坐标高亮和 FE8 的普通／发光高亮需要“清除持续高亮”。高亮固定在创建时的位置。

FE8 可用以下顺序编排带条件的招募场景，例中人物使用明确 ID，槽 1 需由该脚本保留使用：

1. 将槽 1 设为 0，插入“检查单位存活 → 槽 C”。用相等分支比较槽 C 与槽 1，结果为 0 时跳到收尾标签。
2. 插入“检查单位出场 → 槽 C”，同样在结果为 0 时跳到收尾；存活检查已排除了单位不存在的情况。
3. 镜头移至人物并高亮，加入对话及相应的开始、等待、清除文本指令。
4. 对话后加入我方，移动并等待到达，再设置槽 3 并给予道具。
5. 定义收尾标签，清除持续高亮并结束事件。每次单位检查都会覆盖槽 C，比较应紧随所需结果。

“检查单位存在”涵盖所有阵营，不代表已招募；阵营查询返回 0／1／2（我方／友军／敌军）。出场和阵营查询要求单位存在。FE6／FE7 提供的是“无存活／出场我方人物时跳转”，直接指定人物与标签，只检查我方队伍，不能替代对敌军或友军的存在检查。

FE8 加载单位时，在 LOAD1／LOAD2／LOAD3 中选择已有部署组，检查加载参数，随后插入“等待单位移动”，再接镜头、对话、招募或奖励。LOAD2 固定使用参数 2，新加载的我方单位按剧情单位处理；永久加入我方通常使用 LOAD1。LOAD3 按当前我方队伍替换模板人物，不直接采用编辑器中显示的模板人物名单。

通过槽 2 加载时，可先将部署的 GBA 地址赋给槽 2，再把 LOAD 地址设为 `0xFFFFFFFF`。队列路径则先设置槽 D 为 0，将部署地址赋给槽 1，执行“槽 1 入队”，再“出队并写入槽 2”，最后加载并等待。队列按先入先出取值，槽 1 后来的改写不会改变已入队的值。无需队列的场景可直接选择部署组。

FE7 的路线文本和四路部署各自显示独立引用选择；先选择对应的路线／难度分支，再修改或打开资源。普通四路加载可用零地址跳过一支，当前队伍模板须填写每个分支。选择结果分支的两个原生编码都检查“不是 YES”，以界面说明为准。

FE6／FE7 手动移动指令可在参数区编辑路径步骤。选择步骤后插入、删除、上下移动或修改停顿／速度；末尾停止指令保留。无可解析路径时，可明确新建替换路径。点击脚本预览会显示追加路径数量，应用时同时写入路径和指令引用；撤销会恢复引用及文件长度。FE7 两路路径可分别修改，其他独立引用继续使用旧路径。

FE8 槽运算分别选择目标槽和两个输入槽；只有能证明数值不变的复制保留资源来源。计数器、查询和单位状态操作的槽输入／输出见指令帮助。新增等待至少 1 帧；FE6／FE7 的“清除跳过状态”会继续执行，需要结束时另加“结束”或允许后续标签查找的“提前返回”。

来源能够确认时，加载行会显示部署地址和赋值位置，可跳到部署页编辑。多个加载共用同一赋值位置时会一起受该部署编辑影响；若只想更换当前加载，直接在该 LOAD 中选择另一组部署。无法确认来源时仍可保留原编码、编辑独立参数或明确指定直接部署地址，整段结构搬迁保持受限。

参数修改写入原地址，会影响已知共享及内部入口。插入、复制、删除和重排要求整段指令均可确认并静态重定位，应用时追加脚本并更新选定入口，其他独立入口继续使用旧脚本。

草稿先预览再应用，文档或布局改变后重新读取。静态发现不执行条件、分支或 ASM，不能保证识别自定义引擎引用。条件编码与共享语义见[章节与事件参考](reference/chapters-and-events.md)。

## 高级操作

领域页面不设统管全页的“原始数据”开关。道具特性编码、章节标识、FE8 部署的位置标志和商店补丁参数直接列在所属表单中，不再为单个字段增加折叠入口；人物／职业仍以独立标签承载文本 ID、排序等字段。简短规则放在控件帮助中，头像地址清单省略；未知指令等必要诊断就近显示。添加、复制、删除和重排等重复列表操作使用符号按钮，提供完整提示及可访问名称；应用、预览和放弃草稿保留明确文字。

独立十六进制编辑接受 ROM 偏移或 `08`／`09` 开头的 GBA 地址，每次读取 1–4096 字节；应用保持长度不变，并检查读取后的修订。

“表定位”可指定地址、记录大小与记录数。地址和记录大小需 4 字节对齐，范围必须容纳现有字段。设置仅影响当前窗口的解析，不改写指针、不随 ROM 保存，可恢复自动定位。

自动定位时可“预览搬迁”，核对源／目标、字节数、已确认引用和搬迁后大小，再应用。搬迁保留旧表和结束记录，当前不会增加记录数；未知引用仍可能读取旧副本。

## 模拟器

试运行前先保存 ROM。模拟器启动优先使用 `FEBUILDER_EMULATOR` 指定的可执行文件，其次使用 PATH 中的 `mgba`，macOS 也支持 `/Applications/mGBA.app`。

配置值必须是可执行文件路径，不能附加命令参数。当前只支持启动，未接入跳章或内存调试。文件编辑和保存重开成功不代表游戏内行为已经验证。
