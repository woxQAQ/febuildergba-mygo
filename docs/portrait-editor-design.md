# 头像编辑页

状态：已落实头像编辑页修订，覆盖 FE8U、FE8J、FE7U、FE7J 和 FE6 的原生头像。本文截图来自实际 MyGo 页面和原版 FE8U 数据。

## 页面组织

人物 ID 与头像 ID 独立，例如人物 01 引用头像 02。人物页决定使用哪份资源，头像表管理这份共享资源的组成、定位和显示方式。

左侧以小头像、头像 ID 和已知使用者浏览记录。中央同时显示大头像、小头像与表情检查图，右侧提供定位、默认眨眼方式、部件地址与高级入口。窄窗口把右侧设置移到预览下方，所有主要区域均可滚动。

另见[窄窗口](images/portrait-editor-narrow.png)、[整张素材](images/portrait-editor-sheet.png)和[FE6 页面](images/portrait-editor-fe6.png)。

## 视觉规则

沿用现有桌面编辑器的系统字体、强调色及中性底色，视觉重点放在真实像素图和定位关系。

| 颜色 | 用途 |
| --- | --- |
| `#FFFFFF` | 页面与主工作区 |
| `#F4F4F6` | 输入区及透明图预览底 |
| `#D8D8DE` | 输入边界与分隔 |
| `#1D1D1F` | 主要文本与字段值 |
| `#6B6B6B` | 说明、单位和不适用项 |
| `#C44B2C` | 当前选择、焦点与定位框 |

正文 13、辅助文字 12、当前头像标题 20；ID 和坐标使用等宽数字，地址使用等宽字体。名称、标签和说明左对齐，数值右对齐。区块间距 16，组内 6–8。图像使用整数倍像素缩放，不添加自动播放或装饰背景。

大头像、小头像和表情检查图按任务使用不同尺寸。设置直接围绕部件定位组织，不用等大卡片包装不同功能。

## 部件与表情

- 主视图支持 1×／2×／3×，可切换效果预览和整张 PNG 素材。
- FE7／FE8 提供默认、睁眼、半闭、闭眼，以及原图和七个口型；闭眼＋口型检查图独立显示。
- FE6 提供原图与五个主图内口型，没有独立眼睛或默认眨眼控件。
- 预览帧、缩放、素材视图和定位框设置保留在窗口内，不写 ROM、不进入 ROM 历史；眼睛和口型两行属于同一控制组，组内间距为 6。
- 已知使用处显示目标记录种类、ID 和名称，字段名放入提示；无名称时保留种类与 ID。
- 调色板显示 16 色，颜色 0 标为透明。颜色修改仍通过完整 PNG 预览和应用流程进行。
- 空入口、缺少部件和损坏引用分别处理。主图、小头像和素材表独立读取；某个表情帧不可用时保留可读主图并显示原因。
- 职业卡仅提供自身预览、调色板和有效资源入口，不显示眼口定位或表情控件。

## 定位与历史

| 原生布局 | 记录长度 | 嘴 X／Y | 眼 X／Y | 默认眨眼 |
| --- | --- | --- | --- | --- |
| FE6 | 16 | +12／+13 | 不存在 | 不存在 |
| FE7U／FE7J／FE8U／FE8J | 28 | +20／+21 | +22／+23 | +24 |

坐标每格 8 像素，叠加部件为 32×16 像素。点击对应坐标会选择嘴或眼的定位框；拖动定位框按格对齐。数值允许原生无符号字节范围 0–255，保留已有超出可见范围的值；图上拖动限制在可见头像内。

有效数值输入立即写入文档，非法或不完整输入保留草稿，切换预览方式后仍可继续。上下键微调，Cmd+Z／Cmd+Shift+Z 使用 ROM 历史。拖动时只改变窗口预览，松开后把 X、Y 一起写入，一次撤销恢复两个坐标。

眨眼方式选择器提供已确认的正常 1、闭眼 6，其他值原样显示；高级区可编辑完整原字节。每次结构化写入只修改已确认的字段，保留指针、其他记录和未解释字节。操作绑定文档身份、revision 与窗口布局，旧截图对应的写入对象在修订、布局或表入口变化后失效。

## 素材与地址

PNG 导入导出针对完整素材表，继续使用现有颜色校验、共享影响、预览、应用／取消和原子历史。图片应用保留眼口坐标与眨眼方式，替换后可直接检查表情和定位。定位修改会令先前的 PNG 预览失效。

部件列表默认显示主图、小头像、口型、调色板、职业卡的 ROM 文件地址。地址本身可聚焦，点击或 Enter 跳到经过范围校验的原始字节；Cmd/Ctrl+C 或右键菜单复制完整地址。空指针显示无资源，损坏指针显示原因。高级区提供原始记录字节和指针所在位置，原始修改继续使用已有十六进制编辑器。

头像表跟随实时表指针，保留表内空洞，省略末尾空记录；最多发现 4096 条，连续 1000 个空记录停止。引用中的损坏记录仍可见，避免一个坏部件隐藏后面的有效记录。缩略图按可见行加载并随文档修订失效。

已知 MUG_EXCEED／HALFBODY 格式保留既有静态预览；其定位和完整素材写入不按原生布局推断。新建头像 ID、头像表扩展、自定义引擎及自动表情播放尚未接入。

## 人物与职业页

身份区并列显示大头像和小头像，直接提供头像 ID 输入与“前往头像表”。修改引用不再需要先切关联数据；进入头像表时选择目标并保留完整列表上下文。

人物头像 ID 为零时解析当前默认职业的头像，界面标明继承来源，保留人物原值零。默认职业仍可能被章节部署覆盖，预览不代表特定场景中的实际单位。

人物小头像值零沿用实际头像，非零来自通用小头像资源，显示原值与来源。五版原生通用图像／调色板表单独读取，不把该值当作普通头像表 ID；有效像素提供真实字节入口。通用小头像扩展补丁不按原生表解释，专用 PNG 编辑器尚未接入。

## 实现边界与验证

- [portrait_editor.go](../game/portrait_editor.go)：独立部件读取、原生帧组合、可写字段、修订绑定与原子定位。
- [record_portraits.go](../game/record_portraits.go)：人物／职业引用、职业回退、小头像来源与原生通用资源。
- [portrait_table.go](../game/portrait_table.go)：有界索引、空洞、损坏记录及已知使用处。
- [portraits](../internal/pages/portraits)：缩略图列表、预览、定位输入、拖动、资源导航与 PNG 工作流。
- [recordform](../internal/components/recordform)：人物／职业身份区和引用入口。

领域流程使用独立字节样本验证五版图块位置、表情帧、部件损坏、未知字节、原子历史、过期写入、手动布局、头像表搬迁、PNG 与定位的相互失效、职业回退、通用小头像及保存重开。真实 ROM 回归固定五版头像 02 的地址和坐标，并验证原生渲染、字段修改、来源、历史与保存重开。

MyGo 交互复核使用临时探针，覆盖五版输入、非法草稿、帧选择、拖动、撤销重做、PNG 预览／应用、宽窄窗口、中英文和资源跳转。不新增永久 UI 测试，不执行游戏内验证。
