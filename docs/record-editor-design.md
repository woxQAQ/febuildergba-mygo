# 人物与职业编辑页

本文维护人物与职业页的交互和字段语义，功能状态见[覆盖矩阵](coverage.md)。截图为固定提交 `a164bd7` 下的历史 MyGo 页面，仅用于追溯设计，不代表当前版本的渲染。

## 页面与数据来源

人物页显示个人修正、成长率和默认职业的参考能力，职业页显示基础、上限、成长率及转职加成。左侧提供搜索、多选、批量编辑和表定位；人物列表仅在人物自身配置非零头像 ID 时显示头像，不用职业回退头像或空占位。职业列表显示待机首帧的可见像素，裁去透明边缘，以实际宽度和最多 22 像素高度排入文本行，不预留头像方框。右侧提供能力与特性和原始数据标签；人物另有支援、死亡对话标签，职业另有移动与地形标签。

顶部作为紧凑的基础信息区，随编辑区的可用宽度伸缩：左侧显示头像与小头像，右侧集中显示名称、简介、职业、等级与属性，记录 ID 作为次要信息显示。名称与简介直接编辑，文本 ID 仅在“原始数据”中作为数值编辑；没有 ID 时直接提供设置按钮，显示并聚焦对应字段。常用字段的标签位于控件上方。职业、等级、属性、小头像来源及版本特有字段共用一个横向流布局，字段宽度按内容保持紧凑，空间足够时一行排完，不预设分行。名称与简介随可用宽度伸缩；极窄时控件按可用空间收缩。职业选择旁显示所选职业的待机图，属性选择旁显示对应原生属性图标；属性为零或未知、图像不可读时保留文字，不生成占位图。职业引用末尾的 `↗` 图标打开当前引用，悬停说明目标，字段内支持 `Alt+Enter`。宽度不足时字段组完整换行，更窄时资料排到头像下方。两页均以独立“原始数据”标签集中显示高级字段，不展开整条记录的十六进制字节，也不提供记录或关联资源的字节编辑入口。

普通数值的有效输入立即修改内存文档，非法或不完整输入保留为草稿。名称和描述先预览，再原子应用。字段操作与说明位于对应控件，人物页和职业页分别保留侧栏宽度和记录状态。

## 能力矩阵

能力按 HP、力量／魔力、技巧、速度、防御、魔防、幸运、体格和移动固定横排。字段缺失的单元格显示 `—`，全局规则不作为本记录的字段显示。

人物默认显示个人修正、成长率和一行初始参考。打开线性估算后，该行改为目标等级的估算值。打开职业来源后，增加职业基础行。

职业默认显示基础、上限、成长率和转职加成，估算由用户打开。FE6 没有转职加成字段，不显示这一行。

参照和估算数值使用正常正文色，以无边框文字表达只读；灰色用于帮助、来源和不适用项。区块间距为 16，组内主要为 4 至 6，保留紧凑数值行。窄窗口只对过宽矩阵局部横向滚动，特性组调整为两列。

### 字段范围

已依据 FE6／FE7／FE8 原生人物和职业结构核对：

- 人物初始等级及个人修正按有符号字节解释；人物成长率为无符号字节。
- 职业基础、上限、成长率和经验计算参数按有符号字节解释。
- FE7／FE8 的转职加成为无符号字节，FE6 对应位置不生成此组字段。
- 武器熟练度为无符号字节，特性保留完整 32 位编码。

读写按字段范围校验，保留其他字段及未知字节。

### 参照与估算

人物使用 `class_id` 指定的默认／参照职业。章节部署可以覆盖职业，界面结果不代表实际出场状态。职业记录的 `promotion_id` 显示为"关联职业"：FE6／FE7 用作转职目标，FE8 的高级单位自动成长与经验计算会用它取得低阶参照职业，实际转职分支是独立规则。固定旧版日文标签为“クラスチェンジクラス”，英文译为“Menu Class”，中文译为“职业更换职业”；版本用途依据 `FEBuilderGBA/FEBuilderGBA/InputFormRef.cs` 的 `@CLASS_CC` 说明及[固定 FE8U 源码](https://github.com/FireEmblemUniverse/fireemblem8u/blob/04d1edb163d14bd10777a065697e1a9f17be65f2/src/bmunit.c)的 `UnitAutolevel`、[经验计算](https://github.com/FireEmblemUniverse/fireemblem8u/blob/04d1edb163d14bd10777a065697e1a9f17be65f2/src/bmbattle.c)的 `GetUnitPowerLevel`。

初始参考按原生规则计算。常规能力是职业基础加人物修正，幸运来自人物，体格包含人物修正，移动来自职业。职业缺失或引用无效时显示原因，普通字段仍可编辑。

线性估算公式为 `参考初值 + 成长率 × 成长次数 / 100`。人物成长次数等于目标等级减初始等级。职业直接输入成长次数，使用职业成长率。

计算以整数保存百分之一单位，显示时保留有效小数。职业幸运等字段没有起算基值时，不显示绝对估算值。

估算不计上限、转职、随机升级、难度加值或事件变化。参照设置只保存在窗口，不写 ROM、不进入 ROM 历史，输入框使用自己的文本撤销。

## 武器熟练度

武器熟练度紧接能力矩阵，位于同一能力区域，不另设标题或独立分组。每列显示 ROM 原生武器类别图标、当前有效等级和精确原值；名称保留在悬停帮助及可访问标签中，图像不可读时回退到名称。点击武器等级标题，就地展开等级菜单；标题可用 Tab 聚焦，Enter、空格或下方向键展开，Esc 关闭并返回焦点。下方数值框直接编辑精确熟练度。

- 直接改数值会更新等级。
- 改选等级写入该版本的最低熟练度；选择原等级保留等级内进度。
- 人物原值 0 沿用默认职业，非零值覆盖职业值，即使它更低。
- 继承来源和原始值含义在字段帮助及等级菜单中显示，菜单勾选当前存储等级。
- FE6 的 D／C／B／A 最低值为 51／101／151／201，FE7／FE8 为 31／71／121／181，S 均为 251。

## 特性

四组复选框分别对应四个原生字节。组头显示十六进制字节值，勾选只修改对应位，保留其余 31 位，并形成一次文档历史操作。

定义按版本区分，例如同一位置在 FE8 为召唤、FE7 为掉落道具。没有确认语义的位显示位号并保持结构化只读；高级区保留原始编码入口。

人物复选框只修改人物标志，不把职业效果写入人物位。游戏根据实际部署职业组合双方特性，移动消耗和技能等规则另有数据来源。

## 头像与图像操作

人物／职业身份区并列显示主图、小头像及职业回退来源。点击主图进入实际头像资源，右键“更换头像…”在当前页打开带缩略图、ID 和已知使用者的选择器；可按十六进制 ID（可带 `0x`）或名称搜索，确认后只更新当前记录引用，取消不写入，支持一次撤销。人物菜单另提供“沿用默认职业头像”，职业菜单提供“不设置头像”；没有头像时点击占位区域选择。头像可用 Tab 聚焦，Enter／空格打开，菜单键／Shift+F10 调出右键菜单；取消选择后恢复入口焦点。头像 ID 不再作为普通或原始数据表单字段出现。选择器绑定文档、修订与布局，过期后不能提交。小头像仍显示沿用或原生通用来源，不在身份区提供像素字节编辑入口。PNG 导入导出集中在独立“头像”面板。

头像表统一列出人物头像和职业卡，支持：

- 按头像 ID、0x 前缀或已知使用者名称搜索。
- 主图、小头像与表情检查，整张素材、缩放、定位框、眼口坐标及默认眨眼编辑；FE6 按独立原生布局提供口型与嘴定位。
- 数值即时写入与原子拖动历史，有效部件位置只读核对。
- PNG 导出、替换预览、共享使用处、应用／取消和既有原子历史。
- 跳回引用此资源的人物或职业。
- 跟随当前 ROM 的头像表指针；保留表内空洞，省略末尾空记录，最多发现 4096 条并以连续 1000 条空记录作为探索边界之一。

PNG 控件共用 `components.AssetEditor`，道具图标和头像表使用同一流程。仍不提供新建头像 ID、头像表扩展或自定义引擎写入。

五版定位、表情、拖动历史及小头像来源的规则和历史截图见[头像编辑页](portrait-editor-design.md)。

## 基础字段与专用编辑

职业地图图像、行走速度和经验参数与人物基础数据采用同样的顶部表单；地图图像编号旁显示待机首帧预览。人物动画调色板或对话语气等已确认版本字段也放在顶部。不再提供关联数据标签。排序、访问分组及名称／描述文本 ID 收入原始数据区，按普通数值字段即时写入，不重复显示文本选择器或正文。职业行走速度提供枚举选择，未知值保留数值。

移动消耗及地形加成由“移动与地形”编辑，不再列出资源指针和“编辑字节”替代入口。战斗动画尚无专用编辑器，不以字节跳转充当编辑流程。人物“支援”标签编辑关系、初始值和增长值，提供增删、可选的反向同步及独立预览。关系行可跳到独立对话面板的相应人物组合；对话面板可返回双方人物的支援标签，详见[支援参考](reference/supports.md)。FE6 不生成不存在的雨／雪入口。

职业的“移动与地形”标签以地形行、原生列提供草稿编辑及共享预览，按列独立追加并原子应用。详细长度、数值及边界见[地形参考](reference/terrain.md)。支援属性加成、转职分支、技能和战斗动画的范围见覆盖矩阵。未知偏移和补丁字段不提供结构化编辑。

## 交互与边界

人物“死亡对话”标签默认显示一份正文和编辑动作。单条通用对话不显示范围选择；已有章节／路线限制以实际范围作为入口，多条情形才显示切换。FE7 普通、琳篇和其他篇章的现有记录在同一个情形选择器中浏览，各表的顺序及草稿仍保持独立。非零死亡标志和 FE6 已有终章文本提供紧凑入口；实际使用脚本时直接提供脚本字节查看。空状态提供添加台词，缺失的 FE7 篇章脚本可从操作菜单新增。

“编辑台词”进入文本页，“更换台词”打开独立选择任务。对话引用或范围有未应用修改时，编辑动作先生成审核，以“应用并编辑台词”提交引用后导航，避免正文编辑使引用草稿过期。操作菜单中的范围、死亡标志、备用脚本和终章文本各自打开对应任务；取消或 Esc 不改变对话草稿，关闭后恢复操作入口焦点。“改用脚本”明确清空本条文本字段，普通更换文本保留已有备用脚本。

“添加特殊对话”要求明确选择章节／路线与内容，完成后才复制当前记录的保留字节及死亡标志，并将新特例插到该人物当前表的第一条记录之前；原记录和其他人物的相对顺序保留。复制、删除和移动位于操作菜单，匹配规则与原始记录按需查看。删除最后一条记录后仍保留该表的待应用入口。每个人物／表拥有独立草稿；写入仍使用完整原生表的不可变计划，其他人物的未提交草稿不会一并提交。文本使用处返回相应人物和物理记录；仅正文修订时保留原记录选择，应用后保留提交后的物理记录位置。详见[对话参考](reference/battle-and-defeat-dialogue.md)。

缩略图由 `components.Thumbnails` 缓存，成功与失败均绑定文档、修订和布局；人物复用头像来源选择，待机与武器图标由 `game/sprite` 只读解析。原生格式与限制见[图像参考](reference/text-and-images.md#列表缩略图与武器类别图标)。

数值右对齐并使用等宽数字；地址和原始字节使用等宽字体。系统字体与已有强调色保持一致。Tab 遍历可编辑控件，上下键微调数值。数值框的右键菜单保留文本编辑命令，并提供加减操作；原始数据标签中悬停显示地址和十六进制值，已解释字段仍通过表单修改。字段名称、范围和操作提示位于输入框帮助，非法输入就地标记。数值字段的可见标题通过 `LabelledBy` 与输入框关联：标题携带“分组／字段”的完整可访问名称，点击标题聚焦对应输入框，输入禁用时点击不转移焦点。普通数值使用 ROM 历史，名称、正文、搜索、估算设置、支援及地形数值草稿使用对应文本历史。

`records.Page` 负责导航、多选和表布局，同包的 form 提供人物、职业详情及数值、文本控件。`portraits.Page` 处理头像资源编辑。页面通过回调导航，app 打开原生文件对话框。

`game` 提供字段、位定义、武器等级与继承、只读能力参照、资源指针和头像索引。UI 使用这些结果，不解析偏移或通过显示名称推断规则。当前只增加具体功能需要的定义，尚未迁移完整 metadata 库。

## 验证范围

合成样本的领域流程覆盖五版字段范围、位掩码、武器门槛与继承、同等级保留进度、参照与估算、未知位、布局变化、表搬迁、头像表发现与引用、原子历史、保存重开及继续编辑。固定预期使用合成样本，可选集成流程使用 `.rom/` 中动态发现的输入；纯布局调整无需专门测试。

开发模式的 ROM 路径恢复见[开发说明](development.md#开发启动)。
