# 实现记录

当前支持 FE8U、FE8J、FE7U、FE7J 和 FE6 的人物、职业、道具与章节配置基础编辑；日文适配面向原版。支持名称、素材及章节静态地图预览、头像／职业卡／道具图标的 PNG 导出和替换、FE8 完整部署移动路径，以及批量修改、手动表定位、固定长度十六进制编辑和已有表搬迁。表搬迁可原子更新已确认引用并扩容，五个版本均已接入名称、描述及已有文本 ID 的正文与控制指令编辑，并支持初始部署记录、增删复制、地图定位、回合／区域条件与新建增援、人物对话条件与普通对话脚本、胜败标志条件和原生全灭模板、通用脚本浏览与常用指令编辑及原子写入；表记录数扩展、新建文本 ID、其他图像写入、地图绘制、其他触发条件、更多脚本指令和跳章尚未实现，完整功能状态见[覆盖矩阵](coverage.md)。

范围与开发规则见[重建计划](rebuild-plan.md)，运行、操作和构建命令见[编辑器 README](../README.md)。

错误模型使用 [`fault`](../fault/error.go)，领域包拥有稳定错误码和处理类别，操作边界记录路径、记录、字段、资源、范围与修订；UI 显式映射文案，应用边界通过 `slog` 保留原因树。保存失败区分备份／替换等步骤，地图与图像解码保留底层原因，文本错误保留具体控制码或参数分类。约定与验证范围见[结构化错误设计](error-design.md)。

领域核心不导入 MyGo。普通字段及原始字节操作保持等长；表搬迁把复制、引用更新和必要的扩容纳入同一文档操作，一次撤销恢复字节、指针和原文件长度。FE6 人物表包含隐藏的 ID 0，职业／道具／章节表包含解析所需的结束记录。手动表定位只改变当前窗口的解析设置；当前搬迁入口要求恢复自动定位。普通表有效数值立即修改内存文档，未完成输入及组合文字保留为草稿；部署以入口绑定的草稿及显式预览提交。普通文本草稿使用文本撤销，数值字段使用 ROM 历史。

空间层只更新显式选择且值已核实的引用；表操作从游戏规则中选择引用，不扫描任意指针形状的字节。默认在末尾追加；核心 API 也接受注明来源、与已知表和引用等保护区不重叠的可用区间。界面尚未提供区间声明或全局引用查询。旧区保留，未识别引用仍指向旧副本，不保证未知补丁代码会使用新副本。

FE7U／FE7J 使用 253 条人物记录、52／84／36 字节的基础表布局。FE7U 的 Huffman 根／树指针位置为 `0x6B8`／`0x6BC`，其余当前版本为 `0x6DC`／`0x6E0`；这些位置由各适配器提供。FE7J 使用 Shift-JIS 及独立的紧凑职业名字形映射。头像共用现有读取器，分别验证 FE7U 的 LZ77 数据和 FE7J 的未压缩数据。补丁专属字段、自定义字库和完整游戏代码引用仍待覆盖。

五个版本的名称写入共用当前 ROM 的 Huffman 树：FE8U／FE7U 接受可打印 ASCII，FE8J／FE7J／FE6 接受 Shift-JIS，紧凑职业名通过同一份双向映射还原为原版字形。编码保留完整 Shift-JIS 字符边界，并可使用包含 `0x1F` 名称填充符的原生叶子；填充符不作为结束码。拒绝无法编码或无法原样读回的输入。名称不带首尾空格，解码后的游戏数据最多 4096 字节（包含填充符，不按 UTF-8 长度计）；码长最多 32 位，总位流最多 65536 位。压缩流为英文／日文分别保留最少七／八位结束码空间及三字节读取余量。写入要求有效的主文本表指针，恢复地址只用于读取。预览绑定文档修订和窗口表布局，列出共享该文本 ID 的已知名称、描述、使用描述及章节文本字段；其他描述或事件中使用该 ID 的位置也会变化。写入保留旧文本，在末尾四字节对齐追加资源并更新选定入口，一次撤销恢复指针与长度；未应用的名称输入保持草稿。不会生成 anti-Huffman 数据。

五版描述编辑使用同一套 `TextEdit` 预览与原子提交；记录详情统一提供多行编辑、共享字段预览、应用、取消和只读原因。字段元数据以 `TextRole` 区分名称和描述；`TextValue` 保留正文、换行、控制码及完整 16 位参数。换行显示为实际换行，其他控制使用 `[A]`、`[Wink]`、`[LoadFace][0x0141]` 等可读指令，也接受原始 `[0xNNNN]` 标记，字面 `[`／反斜杠使用 `\[`／`\\` 转义。英文描述接受 ASCII，日文描述接受 Shift-JIS，保留首尾空白及半角字符；紧凑字形在连续正文中双向转换。先识别完整 Shift-JIS 字符，再解释控制码；参数始终作为完整单元保留。正文、已支持的控制指令及参数均可修改；指令需适用于当前版本，字符与参数必须能由当前 Huffman 树无损编码。非法编码、未识别扩展、未支持的组合和不完整参数保留原始表示并只读。等价标记不会触发重编码；不会生成 anti-Huffman 数据。

“文本”标签页按原版规则读取连续有效的文本入口，支持正文或十六进制 ID 搜索、指令参考及 ROM 控制单元查看。RAM 入口参与表范围判定但不可从 ROM 解码或替换，单条损坏不隐藏后续入口；恢复地址仅供浏览。索引随文档修订失效。每个 ID 保留自己的草稿，原文冲突时保留草稿并要求重新读取；预览列出已知字段并可跳回对应记录。新建 ID、扩展文本表、自定义文本引擎、字库、全局事件引用查询及游戏画面预览仍待接入。

五版章节配置复用记录与字段编辑器，规则位于 [chapters.go](../game/chapters.go)。章节名按实际偏移读取，FE8U/J／FE7J、FE7U、FE6 默认分别为 148、152、68 字节；FE6 的 `0x2BB12` 指令 `0x2048` 选择 72 字节布局。保留旧版内部名称指针及缺失指针时的结束判定，解析最多 256 条。基础配置、地图／事件资源 ID、音乐和各版专属文本均按已确认偏移及宽度修改；关联文本进入通用文本页，胜利条件文案与实际事件判定分开处理。章节共用批量、历史、手动布局及原始字节；表搬迁保留旧数据与结束记录，只更新已确认引用，并纳入空间与文本入口保护。未知枚举／补丁语义、资源内容、地图绘制、出击和事件脚本尚未完整覆盖。

章节地图预览由 [maps.go](../game/maps.go)、[background.go](../gba/background.go) 和 [mapview](../internal/components/mapview/view.go) 分别负责资源、GBA 图块和交互。按当前章节地址跟随实时资源指针，支持独立资源列表及两个图块资源拼接；FE6 原版也需要第二组图块。处理调色板、翻转、原始地图单元与地形 ID，按旧版 60×63／1536 格上限检查。章节页内提供缩放、平移、网格、格子选择和重置，缓存绑定会话、文档修订、章节与实际记录地址。错误标明资源类别，配置仍可编辑。底图保持静态，部署视图叠加所选组的序号标记；迷雾、动画、事件地图变化与地图资源写入尚未接入。

五版部署由 [deployments.go](../game/deployments.go)、[deployment_events.go](../game/deployment_events.go)、[deployment_edit.go](../game/deployment_edit.go) 与 [chapterview](../internal/components/chapterview) 分别负责资源、静态引用发现、草稿／写入和章节交互。FE8 为 20 字节记录及 8 字节移动段，FE7／FE6 为 16 字节记录内起终点；保留打包标志、未解释字节和结束数据。解析各难度、路线、遭遇战以及开场、回合、区域、胜败及对话事件中的已确认引用，遇到动态命令、未知编码和限额时保留可用入口并提示不完整，不模拟事件执行。FE6 的两个章节部署入口以真实 ROM 的阵营样本校核，避免沿用旧界面颠倒的标签。

部署草稿支持基础身份、等级、阵营、成长、道具、AI 和位置，以及新增、删除、复制；FE8 支持完整多段路径及零路径创建，末段位置字段继续保留之前的段。预览绑定文档、修订和手动布局；追加记录及需要修改的路径，原子更新选定指针，保留其他入口和原资源。预览列出共用同一指针位置的已知章节，不能穷举所有事件引用。部署资源及入口纳入表搬迁声明区间、文本入口和素材写入保护。地图与列表共享单位选择、起终点模式和格子定位；冲突草稿保留并要求重新读取。初始部署每组上限 256 个单位，事件发现上限为 128 个入口、16 层调用和 8192 条指令。

FE8U／FE8J 完整路径位于 [deployment_paths.go](../game/deployment_paths.go)，以 `MovementStep` 表示原生 8 字节 REDA 的绝对目标、6 位配置、同步人物／进度和前置延迟；完整原始字节随快照提供且不暴露可变内部数据。依据 `muctrl.c`／`muctrl.h`，同步字段用于等待，不是相对坐标；原生缓冲区为 4 组各 16 段。已存在的超长数据可以不改路径而保留，编辑路径在部署及新建事件的规划阶段均校验最多 16 段。支持追加、原字节复制、删除和重排，空路径建立默认段、末段删除清空指针，保留同字的未使用位；同步段 FFFF 表示等待人物整条移动结束，延迟保留 16 位原编码及有符号计时器的回绕语义。侧栏替换单位列表为路径编辑时保持地图可见，节点与列表联动、选格定位、重叠循环、逐段原始字节及字段帮助共用现有控件。每次有效路径修改递增 `DeploymentDraft.Generation()`，令增援旧预览失效；打包沿用统一部署负载，仅复制修改的路径，历史、文档／布局冲突和资源保护共用现有机制。FE6／FE7 的多段移动仍由事件脚本表达。

五版回合增援由 [event_conditions.go](../game/event_conditions.go) 和 [event_edit.go](../game/event_edit.go) 读取条件、绑定草稿并规划原子写入。FE7 类型 1 为 12 字节、其他记录为 16 字节；FE8／FE6 为 12 字节，统一以四字节零记录结束。类型 2 支持起止回合、16 位阵营阶段、完成标志及 FE7 路线／难度；未知类型和脚本保持原始字节，条件类型转换暂未开放。FE8 原生 `EvCheck02_TURN` 与固定 ROM 样本校核结束回合 0／255 及阶段语义。

新建回合增援拥有独立部署草稿，复用人物／道具／AI、地图定位和路径打包。预览将复制后的完整条件表、最小原生加载／等待／结束脚本、部署和修改路径放入同一追加计划，只更新选定事件头的回合表指针。保留旧表、已有脚本和独立入口别名，共用同一指针位置的已知章节在预览列出。条件表最多 256 条，每个脚本独立进行有界静态部署发现；回合表及已识别脚本、指针、部署和路径加入空间保护。草稿绑定文档身份、修订和手动布局，章节表搬迁后重新定位，过期预览禁止写入。已有脚本的单位通过部署页单独编辑。

区域工作流复用 `EventDraft`／`EventEdit`；`EventTable` 区分回合表、常驻表和对话表，`EventCondition` 保留原生条件及独立脚本。常驻表指针位于事件头 `+12`，五版均为 12 字节记录与四字节零结束。类型 `0B` 使用有符号坐标、包含边界；FE8 接受倒序，FE6／FE7 倒序为空范围。地图显示按原生规则计算并裁剪到地图的范围，叠加列表序号，支持重叠循环选择和选格设置端点。完成标志为 0 可重复触发，单次触发需显式选择未使用的非零标志；标志条件及已确认全灭回调在胜败页编辑，其他条件只保留、查看或删除。区域表、新建脚本、部署及修改路径共用一次不可变计划和历史；已有脚本不重写，已识别部署可单独跳转编辑，所有已识别区域资源纳入空间保护。

人物对话复用 `EventDraft`／`EventEdit`，额外脚本与文本发现在 [event_dialogue.go](../game/event_dialogue.go)。对话表在事件头 `+4`，FE6 类型 4 为 12 字节，FE7／FE8 类型 3 为 16 字节；四字节零结束，最多 256 条。FE6 精确匹配双方，FE7／FE8 的发起者 0 为通配。FE7 模式仅占偏移 12 的低字节，高字节保留；FE8 使用 16 位模式，模式 1／2 禁止触发。新建普通对话绑定已存在且可读取的主表 ROM 文本 ID，拒绝 RAM、损坏和恢复表入口；已有文本的只读控制指令可继续被原样引用。文本选择按完整正文搜索，选项使用短摘要，正文在固定高度滚动区预览；可跳到文本页。已有脚本通过有界扫描列出直接文本与已确认槽值，以及已识别部署，不重写脚本。新增对话只生成普通文本展示和清理／结束脚本，条件与脚本统一追加并形成一次历史；旧表、脚本、独立指针别名和未知字节保留，当前对话资源纳入空间保护。招募或其他效果仍由事件脚本定义。

胜败条件复用同一常驻表草稿，具体引用和模板位于 [event_objectives.go](../game/event_objectives.go)。类型 1 的判定标志在 FE8 为 32 位，FE6／FE7 为低 16 位；FE8 的 0 和 100 无条件成立，其余两代引擎的这两个标志为假。完成标志 3 标记胜利，脚本操作数 1 为原生的仅设置标志入口。新增首领击破复用标志 2 和本章结束事件；FE8 全灭使用标志 6，FE7J/U 分别使用 `0x0807AA5D`／`0x08079FE9` 回调，FE6 使用 `0x0806C2F9`，其检查范围包含友军。FE6／FE7／FE8 的结束事件指针位于事件头 `+24`／`+60`／`+76`，跟随当前章节布局定位；新增失败条件优先复用当前章节的游戏结束事件，否则选择可读取的原生入口。已有标志或已确认全灭条件可关联本章已识别脚本和原生标记，不重写脚本；文本引用共用单条预览与选择器。区域与胜败页共用 `EventDraft`，一次预览／历史覆盖两页修改，保持完整表顺序、共享与独立入口以及旧资源。结束事件、部署和路径纳入空间保护。文案编辑独立，其他胜利入口、死亡触发及引擎规则保持有效。

五版事件脚本由 [scripts.go](../game/scripts.go)、[script_schema.go](../game/script_schema.go)、[script_edit.go](../game/script_edit.go)、[script_pack.go](../game/script_pack.go) 和 [script_plan.go](../game/script_plan.go) 负责入口发现、版本定义、草稿、内部引用重定位及写入；独立 [eventeditor](../internal/pages/eventeditor) 页面通过回调连接条件、文本和部署。开场／结束入口跟随当前章节布局，回合／对话／常驻条件及已确认调用按物理指针位置保留别名。单段最多 8192 指令，章节最多 512 入口和 32768 遍历预算，缓存随文档和布局变化失效。仅静态读取；未知及 ASM 指令原样只读，边界或结束无法确认则整段只读。

常用指令覆盖文本、单位加载、等待、标志、标签和调用，FE8 另有槽赋值／比较，FE7 提供已确认标志分支，FE6 原生跨脚本跳转单独建模。参数更新保留地址及其他位，预览列出已知共享和内部入口；结构更新要求整段已确认，验证标签，按稳定指令 ID 重定位已声明的内部调用，追加后只更新选定指针。动态调用或槽值中的不明内部地址拒绝搬迁。记录、指针、事件头／条件、部署与路径等已知区域防止被误作脚本覆盖。草稿与计划绑定文档身份、修订和布局，预览不可变，应用为一次历史，并支持保存后继续编辑和空入口显式创建；未知补丁引用仍不保证完整。

脚本领域流程使用独立字节样本验证共享、内部引用、未知字节、前向标签、插入／删除／复制／排序、动态及资源冲突、文档／布局／预览失效、容量失败、章节搬迁、手动布局和保存重开。真实 ROM 校核五版固定等待指令及最小脚本结构流程，临时内存渲染和交互单独复核，未执行游戏内验证。应用层的 chrome 依赖通过 pages 收窄，纯解析移入 internal/input，并加入导入图检查，避免独立页面依赖记录页内部组件。

人物与职业详情由 recordform 的 profile 布局提供横向能力矩阵、职业／属性选择、武器熟练度、版本特性及关联资源。人物默认只显示个人修正、成长与一行参照，职业来源和线性估算按需展开，结果保持正常正文色。武器区只显示等级及原值，等级选择集中到当前字段检查器。领域规则位于 `record_abilities.go`、`record_weapons.go`、`record_traits.go` 与 `record_resources.go`，校正原生有符号范围，保留未知位和同等级进度；人物非零武器 EXP 覆盖职业，0 继承。

独立头像表由 `portrait_table.go`、`portrait_editor.go` 和 portraits 页面提供有界发现、空洞与使用处、缩略图、主图／小头像／素材表、手动表情帧及部件地址。FE7／FE8 原生眼口定位和眨眼、FE6 嘴定位及内嵌口型分别适配，拖动松开后原子写入两个坐标；预览状态不写 ROM。结构化写入绑定文档、revision 和布局，只修改确认字节。`record_portraits.go` 处理人物原值、默认职业回退及独立通用小头像，身份区直接修改引用；通用图像提供实际字节入口，扩展补丁不按原生表解释。PNG 编辑与道具图标共用 components.AssetEditor，保留预览、共享影响与原子应用；PNG 和定位改变互相令旧预览失效，坐标及未知字节保留。开发启动按 MyGo IsDev 隔离，`app/dev_session.go` 在缓存目录原子保存成功打开的 ROM 路径；无显式参数时恢复，另存为后更新，不自动保存 ROM 修改。五版领域和固定原版记录覆盖这些流程，UI 复核保持临时探针。

五版静态素材共用 `AssetEdit` 与完整 PNG 素材表。图标要求当前共享调色板；头像允许最多 15 种不透明颜色加透明色，转换为 BGR555 后读回预览。FE6 保留主图内嘴部与未压缩小头像布局；其他版本保留独立嘴部、压缩小头像及主图原有压缩方式。头像坐标不改动，素材表未映射区域必须透明。应用在末尾追加各资源，更新已确认的头像记录或图标表入口；图标复制 255 槽可寻址区以保留其他 ID，代价是每次约 32 KiB 的增长。旧资源及独立素材 ID 的旧别名保持不变，预览绑定文档修订与布局，所有修改形成一次历史操作。MUG_EXCEED／HALFBODY 完整素材表写入尚未支持。

核心测试使用修正后的合成标头、表指针与布局，调用实际文档、会话和 LZ77 实现。覆盖五个版本共二十种表搬迁、扩容历史、过期预览、引用及区间冲突、容量上限和保存重开；名称与描述写入另以固定字节样本验证编码、16 位控制参数、跨字段共享 ID 与独立别名、非法树、过期预览和失败原子性。不运行 UI 或模拟器。测试范围及限制见[测试说明](../tests/README.md)。

真实 ROM 检查从 `.rom/` 读取五个原版，验证基础表、表搬迁、字段修改、名称及四类描述写入、五版固定对话的指令增删与头像参数修改、固定章节的配置／关联文本／搬迁、五版固定地图的尺寸／地形／像素摘要、固定部署与事件加载单位、部署修改／增删复制、FE8 双版本固定六段路径字段／增删排序／未知位和独立入口保留及保存重开、固定回合及区域条件修改／新建增援脚本与部署、固定人物对话条件／文本引用与新建普通对话脚本、固定胜败标志／全灭条件及模板、五版固定事件脚本参数与最小脚本结构编辑、删除和继续编辑、图标／完整头像／职业卡 PNG 替换、历史、保存重开和继续编辑。固定记录、文本 ID 和原版空文本的预期由集成用例维护，解析失败不会改选其他记录。检查只修改临时副本，不运行 UI、游戏或模拟器；本地改版 ROM 不在原版验证范围内。
