# FE8J／FE6 基础版本适配验收

FE8J 和 FE6 日文原版已接入现有人物、职业、道具工作区，支持基础字段、名称读取、素材预览、搜索、批量修改、手动表定位，以及统一撤销、保存和备份。此次只确认这些操作的文件及 UI 结果，**章节内属性和战斗效果仍待独立验收**。

## FE8U 回归与当前限制

在独立临时 worktree 中构建 `b9b6e29`，对 FE8U 原版、Vision Quest v3 和 Dream of Five 执行相同的文件操作。当前实现与旧提交的全部表地址、记录、字段数值、名称、补丁状态和所采集非零资源的 PNG 摘要完全一致；相同编辑产生的完整 ROM SHA-256 也一致，包括 Dream of Five 搬迁后的道具表。

本地另有 FE6 翻译版，SHA-256 为 `306123d412ba0aee6701973edb8844505cecde290a645f8c191d10babb836c6a`。探查确认其重用了日文编码槽位，普通 Shift-JIS 会把英文名称误读成假名；本轮没有为其接入自定义字库映射。其标头仍会被识别为 FE6，但不能将本轮原版名称验收结论用于该翻译版。编码槽位仍合法也不证明 ROM 使用原版字形，其他替换字库和补丁组合同样需要对应语料。

本轮曾用 mGBA 核心加载原版临时副本并推进至新游戏开场，尚未进入可核对修改效果的章节状态，没有比较修改副本的游戏属性或战斗结果。这部分不计为修改生效通过，留作独立验收。

尚未完成：FE7J/U、FE6 翻译字库与更多改版规则、日文文本写入、资源导入／扩容／搬迁、章节内修改效果，以及桌面文件选取和真实输入法候选。当前不能宣称阶段 2 完成或各版本功能完全等价。
