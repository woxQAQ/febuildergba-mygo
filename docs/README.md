# 文档索引

按任务选择入口，修改时在对应归属维护。当前实现以源码、测试与运行证据核对；功能状态只由覆盖矩阵维护，历史记录用于追溯。

## 暂缓设计与历史

出现共享定义或社区定义导入需求时，先读[元数据设计的接入条件](metadata-design.md#何时实施与如何接入)，按具体功能提取定义。

已完成的审查、修复、升级与采用方案从[历史记录](../.agents/archive/README.md)进入。活动方案须注明提案状态、基线与触发条件；完成或被替代后的处置见 [AGENTS 的文档生命周期](../AGENTS.md#文档维护)。
