```
└─────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────┐
```

## UI 元素映射

### 使用 Accent (#C44B2C) 的元素
- 顶部工具栏按钮（聚焦/悬停状态）
- 标签页选中指示器
- 列表中选中的记录行
- 文本输入框聚焦边框
- 主要操作按钮
- 复选框和单选框选中状态

### 使用 Success (#4A7C59) 的元素
- 保存成功提示
- 应用批量修改后的确认
- 有效输入范围内的状态指示

### 使用 Warning (#D4941E) 的元素
- 未保存修改的状态指示器
- 外部文件修改警告
- 表定位配置提示

### 使用 Danger (#B3332D) 的元素
- 字段输入错误提示
- 无效十六进制值
- 超出允许范围的数值
- 关闭未保存窗口的警告

### 使用 TextMuted (#6B6B6B) 的元素
- 记录 ID（十六进制显示）
- 文件大小和记录计数
- 字段提示文本
- 允许范围说明
- ROM 版本信息
- 状态栏次要信息

## 视觉特征

### 保持不变
- 间距: 3px（保持数据密度）
- 圆角: 4px（现代但不过度）
- 布局: 三区结构（列表 + 编辑区 + 检查器）
- 字体: 等宽数字和 monospace 十六进制显示

### 新增特征
- 完整的语义化色彩系统
- Fire Emblem 主题一致性
- 清晰的视觉状态层级
- 避免 AI 生成界面的通用模板

## 设计验证

运行应用并检查以下场景的视觉效果：

1. **正常操作**
   - 打开 ROM 文件
   - 选择人物/职业/道具
   - 编辑字段值
   - 观察焦赭红强调色的应用

2. **成功状态**
   - 保存 ROM
   - 应用批量修改
   - 观察森林绿成功指示

3. **警告状态**
   - 修改后不保存
   - 外部文件更改
   - 观察金色警告提示

4. **错误状态**
   - 输入超范围数值
   - 输入无效十六进制
   - 观察深红错误显示

5. **次要信息**
   - 文件大小显示
   - 记录计数
   - 字段提示
   - 观察中性灰弱化效果

## 构建和运行

```bash
# 构建
go build .

# 直接运行
go run .

# 使用 ROM 文件运行
go run . /path/to/FE8U.gba

# 构建 macOS 应用
go tool mygo build
open build/darwin-arm64/FEBuilderGBA.app
```
