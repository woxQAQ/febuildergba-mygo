# 界面设计

面向 FE8U、FE8J 和 FE6 基础数据编辑。以字段比较、键盘操作和密集数据阅读为主；功能范围见[README](README.md)。

## 主题与状态

主题定义位于 [chrome.go](internal/components/chrome.go) 的 `ApplyTheme`，在 MyGo 主题上覆盖以下参数：

| 参数                 | 当前值    | 用途                               |
| -------------------- | --------- | ---------------------------------- |
| `Accent`             | `#C44B2C` | 控件强调色                         |
| `Success`            | `#4A7C59` | 成功状态主题色；具体使用由控件决定 |
| `Warning`            | `#D4941E` | 未保存状态、外部修改提示           |
| `Danger`             | `#B3332D` | 错误及非法输入提示                 |
| `TextMuted`          | `#6B6B6B` | 记录 ID、提示及次要信息            |
| `Spacing` / `Radius` | `3` / `4` | 主题默认间距与圆角，具体控件可覆盖 |

错误和外部修改提示同时提供文字及操作。颜色不是状态的唯一表达。原生窗口和系统对话框遵循平台外观；当前错误与外部修改提示另有固定背景色，不能仅凭主题配置推断其深色模式表现。

## 布局与文字

- 标题栏显示文件名、未保存状态及语言切换。文件操作和撤销使用原生菜单；标题栏留出系统窗口按钮区域。
- 记录页由左侧列表、字段编辑区和底部当前字段检查器组成。侧栏初始宽度为 330；批量修改和表定位在相关操作中展开。
- 职业能力按基础、成长率、上限和转职加成排列；人物使用个人加值及成长率。字段定义决定实际列，缺失项显示 `—`。宽窗口将武器熟练度排在矩阵旁，窄窗口换行。
- 数值右对齐并使用 `tnum` 等宽数字；地址和字节使用等宽字体。记录标题为 20，分组和字段为 13，提示为 12；具体尺寸由控件实现维护。
- 加减按钮集中在当前字段检查器。Tab 切换字段，上下键微调；无效输入和组合文字保留为草稿，不立即写入 ROM。

## 实现位置

[components](internal/components) 定义标题栏、状态提示、文本草稿及 [recordform](internal/components/recordform) 字段布局；[pages](internal/pages) 组合记录导航、批量操作和十六进制编辑。启动与构建命令统一维护在[README](README.md)。
