# 测试

默认测试放在行为所属包的 `*_test.go` 中。领域工作流使用外部测试包（如 `records_test`），通过 `game.Open` 装配真实版本配置，再调用所属编辑器的公开操作；生产包不为测试导出私有配置。

- `romwrite` 的资源编辑工作流组合追加、地址相关编码、替换、搬迁、重定向及原地覆盖，验证固定字节、独立引用与旧载荷保留、预览副本隔离、编码／引用／归属／交叠／容量失败后的继续规划，以及整次提交的撤销重做；另验证文件偏移 0 与空指针的区别。
- `game/edit` 的捕获与提交工作流验证输入及 stamp 配对、冻结后的副本隔离、文档／修订／布局失效、字节操作的布局独立性，以及一次撤销重做；撤销恢复原字节不恢复旧计划的有效性。
- `game` 根目录验证会话、版本装配和整体错误工作流。
- `records`、`text`、`portrait`、`graphics`、`deployment`、`event`、`maps` 验证各自的编辑行为、错误边界和文档历史。`records` 的道具特性流程通过五版真实会话配置检查独立于人物／职业的位定义、世代武器锁差异、单个位写入、未知位与指针保留、失败原子性、历史及保存重开；手动布局流程验证写入遵循当前选定道具表。道具效果流程核对五版编号差异、同编号特殊伤害的世代语义、FE8 石化及问号／补丁编号排除、定义副本、单字段写入与独立效果／指针保留、失败原子性、历史和保存重开。
- `event` 中的商店流程通过章节操作组合 `shop` 草稿；`shop` 验证默认货物、准备及世界地图入口、空指针回退、有效空列表、节点未知字节、独立引用、原生容量和原子历史。
- `event` 的文本使用处流程通过五版固定直接操作数、共享入口和静态调用验证反向查询与可导航指令；包含 FE7 两路文本、FE8 世界地图合成文本字、目录角色、循环、部分脚本只读引用、未知／动态／损坏输入和扫描限额。单条与文件预览保留相同引用范围，脚本编辑、文档／布局变化及撤销重做刷新缓存；动态 `text-script-uses` 从当前输入选取可编辑脚本文本，验证替换、历史与保存重开。
- `event` 的独立对话脚本通过 `quote_scripts_workflow_test.go` 验证 FE7／FE8 四版原生表角色、物理记录和独立指针、静态调用、分离消费者、部分脚本、未知／动态引用、入口及指令预算、领域只读限制、布局／修订失效，以及单条／文件文本预览、撤销重做与保存重开；FE6 不创建脚本目录。动态 `quote-scripts` 按当前输入发现可浏览脚本及可编码文本，验证只读导航和文本替换后的历史／保存重开，不绑定原版地址或正文。
- `event` 的世界地图流程使用独立目录和指令字节，验证事件 ID 关联、静态调用引用、上下文隔离、共享及未知指针、保留位、空入口、结构追加、损坏前缀保护和失败原子性；旁白场景另验证文本半字合成、头像参数偏移／符号、保留位、素材校验、新建与结构搬迁。动态 `worldmap-events` 流程选择可编辑路线参数，`worldmap-scenes` 选择完整可重定位的旁白场景并更换文本／头像、插入路线指令，检查旧代码及独立指针、撤销重做与保存重开。
- `event` 的 FE6 世界地图样本验证章节 PLIST 选择、0／255 索引、共享站点与独立别名、确认指令与保留位、空入口及结构编辑的历史与保存重开、损坏普通事件头下的独立操作、手动章节布局与失败原子性。地图声明与事件声明在实际写入中互相检查入口和载荷冲突。动态 `worldmap-fe6-scenes` 选择可读取的旁白、头像与缩放参数验证精确字节、历史和保存重开；只有被选场景本身允许搬迁时才继续结构流程。
- `event` 的 FE7 世界地图样本验证独立 45 项目录、章节关联、结局、直接文本字、四槽头像／五槽对象、原生长度、配置与时长保留位、负延迟、ASM 跳过回调、空入口及结构搬迁，以及损坏目录／章节和失败原子性。动态 `worldmap-fe7-scenes` 按能力选择可读旁白、头像与镜头参数，检查精确字节、历史和保存重开；不要求实际场景可搬迁。标记样本另验证四槽高亮、五槽地点圆点、九项区域图形、立即清除与异步淡出的原生长度、配色高位和未用字保留、结构编辑及失败原子性；动态 `worldmap-fe7-markers` 选择已有高亮与圆点，验证区域／延迟／位置／配色及历史和保存重开。
- `worldmap` 验证 FE8J/U 节点和路线的独立固定字节、符号边界、保留位、地名使用处、整条记录冲突及过期计划；路线另含共享轨迹隔离、空指针创建／清空、六点上限、递增进度、连接容量、未知结束字节和 ROM 容量失败。底图及道路用固定颜色验证调色板行距、重复计数、翻转和透明色；道路另以固定流验证重叠与跨行、稀疏编码、透明格与缺省格、笔画历史、空道路、联合提交及共享隔离。动态文件流程按可用节点／路线修改坐标、引用、控制点或道路格子，验证原子历史、其他引用保留与保存重开。
- `worldmap` 的底图流程验证索引 PNG 的四组调色板、固定图块字节和 GBA 颜色、行填充及保留位、源资源与独立引用、组合与部分追加、失败原子性、后台导入的不可变输入及过期拒绝；动态 `worldmap-background` 流程导出并修改当前图像，通过实际文件保存重开检查索引和静态渲染。暗色流程验证只替换独立配色、拒绝像素与分组变化；道路图块流程验证固定图块顺序、透明色、末行填充、翻转与布局草稿叠加、共享重载／独立引用、部分分配及失败原子性。动态 `worldmap-dark-palette`／`worldmap-road-tileset` 通过当前导出图修改像素或颜色，检查限定指针变化和保存重开。
- `itemicon` 的图标表流程核对五版原生数量、搬迁表窗口、保留 FF、独立固定像素及损坏指针隔离；图标 0 保留，原生无道具记录 0 从浏览引用与 PNG 共享用途排除，无名称的有效引用保留，原记录字节不归一化；浏览只读，引用切换只写当前道具、支持撤销，引用发现遵循手动道具布局，来源在文档、修订或解释变化后失效。
- `sprite` 通过实际会话验证五版待机首帧、停止动画标记、武器图标裁图及七种属性图标、武器／道具调色板区分、透明色与固定像素、修订／布局失效、损坏或越界指针隔离及读取不写 ROM；动态集成按当前职业和可读资源检查缩略图。
- `maps` 的 `.mapchip_config` 流程验证独立固定原始字节、文件与手动草稿隔离、短配置未解释区、非法组成／长度失败、共享与独立入口、冻结预览及原子历史；动态 `map-tileset-config` 按当前可读配置导出、修改文件并导入，通过临时副本保存重开。
- `maps` 的图像与单组配色联合导入通过 `graphics_palette_workflow_test.go` 验证五版两份资源、常规／迷雾目标组、固定 4bpp 和 BGR555 字节、半字最高位、图像与配色不同的共享集合、独立入口、只搬迁变化资源、不可变预览、一次历史及失败原子性；动态 `map-graphics-palette` 按当前可读资源导出并修改索引 PNG，通过实际文件导入和临时 ROM 副本检查历史与保存重开。
- `chapter` 验证章节布局、跨资源引用、脚本与地图关联及尺寸影响。
- `support` 验证五版关系与现有对话的组合写入、反向数值同步、独立共享、空指针初始化、原生消费者、未知字节、冲突与历史；属性加成通过 `bonuses_workflow_test.go` 验证首项匹配、额外 ID、六列写入、尾字节和结束记录、独立输入、冲突与原子历史；真实输入按可编辑能力分别验证关系、对话和加成。
- `arena` 验证五版职业权重与结构操作、固定武器缓冲区、FE8 联机半字、全部消费者、独立及内部共享引用、未知尾部、冲突与失败原子性；动态文件流程按当前可编辑组验证历史和保存重开。
- `terrain` 验证五版移动消耗与加成列、共享天气／职业隔离、部分重叠、未知尾部、冻结计划、手动布局、冲突、容量及原子历史。
- `quote` 验证五版原生战斗／死亡表的顺序、字段、终止记录、已知消费者、独立共享、扩展角色字保留、冲突和失败原子性，以及历史与保存重开；FE8 另验证双方、攻击方／反击方单人及三角攻击条件在同表中的组合创建。
- `text` 的文本文件流程使用五版固定 Huffman 数据验证旧版 UTF-8 分段字节、原生／FEditor 参数、语言条件、字面分隔符、连续换行和空文本、未改只读内容、批量预览及共享用途副本、未知字节和独立别名、一次历史与保存重开；重复／无效 ID、错误编码、保护冲突、部分分配失败及跨文档／修订／布局失效保持整批原子性。动态 `text-file` 按每份 ROM 的可读及可编码能力选择两个已有 ID，通过文件导出、修改、导入和临时副本保存重开检查。
- `text` 的正文摘要检查保留换行、段落、动态替换、未知标记和字面括号，跳过完整头像参数及已知表现指令；原有源文本、写入及历史流程同时验证。

- `internal/editor` 的文档视图工作流通过实际字节编辑、撤销重做和会话替换，验证共享文档、历史刷新、忙碌与诊断，以及各窗口独立的文本／草稿历史目标和旧字节草稿拒绝。
- `internal/applog` 的日志会话验证分级过滤、结构化原因树、文件保留与降级，以及近期快照的并发读写和副本隔离；查看器日志流另核对稳定接收序号、环形淘汰、跨窗口属性、选择副本及复制 JSON 与磁盘格式一致，固定记录验证完整错误原因；并发读取同时检查接收序号递增。组合 Handler 还通过标准库 `testing/slogtest` 校验属性与分组契约。该包随 `just test-race` 验证，不代表 UI 线程和异步回传已被 race 覆盖。

共享样本和临时会话打开见 [internal/testutil 目录](../internal/testutil/)；领域特有的查找与断言 helper 留在所属测试包。样本明确声明输入字节、地址和布局，不从生产私有配置反推输入或预期，固定预期与容易误解的不变量见 [fixtures.md](../testdata/fixtures.md)。

可选集成测试（`tests/integration`）动态发现 `.rom/` 中的输入，不要求固定文件名或特定原版组合。合成测试与集成测试的写入、保存流程均在临时目录执行；验证范围以测试代码为准。

## 运行

按[开发说明](../docs/development.md#环境与命令)准备工具后，在仓库根目录使用 [justfile](../justfile) 中的 `test`、`test-core`、`test-race` 或 `test-integration`。参数与实际包范围由 recipe 维护；检查选择、UI 临时复核及停止条件统一见 [AGENTS](../AGENTS.md#命令与验证)。

导入边界由 `.golangci.yml` 的 depguard 检查，不在 Go 行为测试中重复实现；规则修改的探针要求见 [AGENTS](../AGENTS.md#命令与验证)。

## 集成输入与范围

集成测试扫描 `.rom/` 根目录中的 `.gba` 文件，扩展名不区分大小写。按标头识别版本，再从当前表、资源和脚本中选择可编辑入口。名称、ID、指针、初始数值和图像内容都来自当前输入；重命名文件、只提供某个版本或使用改版 ROM 不需要修改测试清单。

目录为空、标头不受支持、某项资源不可编辑或追加空间不足时，对应样本或流程明确报告跳过；跳过项不计为通过。选定可编辑入口后，意外的计划错误、应用失败、撤销不完整或保存不一致会使测试失败。缺少某类输入不代表该类能力已验证。

集成侧验证无修改保存、字段编辑、搬迁、文本、头像与 PNG、部署、事件条件、章节／默认／准备／世界地图商店货物、世界地图节点、路线控制点、道路与事件目录、原生战斗／死亡对话表、支援关系、现有支援对话与属性加成、职业移动／地形表及脚本的历史和保存重开流程。固定字节、格式边界和游戏规则的期望保留在合成样本测试中，不从当前实现重新生成预期。

## 测试设计与证据解释

[AGENTS](../AGENTS.md#命令与验证)规定测试对象与验证范围。编解码不能只靠往返测试：编码器与解码器可能共享同一个错误，因此还需对照独立构造的固定字节与手工预期。文件保存重开与合成 ROM 检查也不表示游戏运行正确。

产品功能的实现状态见[覆盖矩阵](../docs/coverage.md)。

## 证据解释

| 证据               | 能说明什么                                         | 不能推出什么                   |
| ------------------ | -------------------------------------------------- | ------------------------------ |
| 合成样本与领域测试 | 固定字节、错误边界、未知数据保留、历史和失败原子性 | 全部真实 ROM 或游戏运行正确    |
| 动态 ROM 集成      | 当前输入中所选可编辑入口的流程与数据一致性         | 未提供的版本、资源或游戏内触发 |
| 临时 UI 复核       | 当次受影响控件的渲染、焦点和操作                   | 后续版本的永久回归保障         |
| 游戏内验证         | 实际执行的版本、章节和场景                         | 未执行的其他场景               |

临时证据只说明当次版本、输入与操作范围，不以临时目录作为长期依据。可追溯入口使用测试代码、固定提交或归档说明；报告要求见 [AGENTS](../AGENTS.md#命令与验证)。历史场景、实际缺陷与测试自身问题的追溯见[临时验证历史发掘](../.agents/archive/temporary-verification-history.md)，其中的旧通过结果不构成当前回归保障。
